# 谷外之光 · 地图工坊

使用 Haiyue Editor 公开能力制作正交几何解谜地图，输出可直接在《谷外之光》中加载的 JSON。包含十二种标准构件、参数编辑、物体组、踩踏开关、错觉接缝和即时试玩。

## 启动

先在 Games 根目录安装项目依赖；Node.js 22+，浏览器需要 WebGPU。然后在 Games 根目录运行：

```powershell
npm --prefix tools/valley-editor install --offline --ignore-scripts
npm run build:valley-editor
npm run build:target -- game:valley-of-light
npm run editor:valley
```

也可以进入 `tools/valley-editor` 后执行 `npm run serve`。打开 <http://127.0.0.1:4178/> 会自动跳转到编辑器；完整地址为 <http://127.0.0.1:4178/tools/valley-editor/index.html>。根地址及目录地址的跳转会保留 `?demo=sea` 等参数。端口可通过 `node tools/valley-editor/serve.mjs 4180` 指定。服务器同时提供 Games 文件，游戏地址为 <http://127.0.0.1:4178/games/valley-of-light/index.html>。

## 制作地图

1. 点击左侧构件，再在视口中按下并松手放置；按住移动时只预览，松手后才生成一个物体。普通路径会显示吸附落点，红色表示该位置已有路径或机关平台，不会重复叠放；Esc 或移出画布后松手取消放置。普通路径默认是 1×1×1 方块，默认按 1 格吸附。将鼠标移到道路边缘或相邻空格时，自动按实际边缘续接，继承道路高度并对齐方向；悬空路径不再落到 Y=0，预览显示目标高度。按住道路拖到更远的空处，会保持起始道路高度。直接在空白处放置时使用工具栏的编辑高度与吸附间隔；海面仍按编辑高度放置。点击已有路径中心不会叠放普通路径。按 Esc 回到选择工具。
2. 拖动物体在 XZ 平面移动。右栏可精确编辑位置、旋转、长宽厚，以及楼梯级数、扭转角、圆弧半径和角度。点击按实际模型表面选中最前方物体，三棱柱的顶面、底面和侧面均可选中，空缺半块不会误选。场景不显示物体名称标签，名称在层级和属性栏查看。网格交点对应路径中心锚点，网格随编辑高度和吸附间隔变化，X/Z 轴以不同颜色标出；右上「网格」可切换显示，试玩时自动隐藏。右键或中键拖动画面，滚轮缩放。点击视口右上「旋转视角」后左键拖动；「复位等轴视角」恢复初始投影。
3. 按住 Shift 多选，在层级栏「成组」。右侧编辑开关旋转轴心，开关动画会围绕该点进行；手轮则绕手轮路径块的中心旋转；物体属性也可指定所属组。
4. 放置 **8 号踩踏开关**，添加目标组动作，填写目标位移、旋转、时长和缓动。一个开关可同时控制多个组；支持一次触发与重新踩入切换。
5. 三维位置相同且表面朝向一致的道路端点自动相连。三棱柱按实际旋转后的切面与投影自动匹配，不要求一定是一个 A 和一个 B。其他道路要制作视觉错觉时，Shift 选中两段道路，在「错觉接缝」中指定 A/B 端点。只有它们在当前正交视角中对齐时，角色才能跨越真实空间的间隔。
6. 放置一个 **9 号出生平台**及至少一个 **10 号出口平台**，点击「试玩地图」。点击道路让角色行走，按住 3 号手轮绕其屏幕中心转动，或拖拽 4 号平移机关。停止试玩后恢复编辑时的初始地图。
7. 「导出地图」下载 JSON；「导入 JSON」重新编辑。也可以在「查看 JSON」中修改文本并应用。所有结构修改，包括导入，都可撤销。

快捷键：Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 重做，Ctrl/Cmd+D 复制，Delete 删除。输入框获得焦点时保留原生文本编辑行为。一次拖拽只产生一条撤销记录；Esc、失去焦点和画布尺寸改变会取消尚未提交的拖动。

默认「开关花园」是一关可通关示例：先踩左边按钮，将两段桥一起移入道路；再走向第二个按钮，转正最后的回廊；最后点击出口。「物体目录」用于查看十二种构件，未连接成完整关卡。

### 整格对齐与机关配色

普通方块、机关平台的锚点统一为顶面中心。示例构件按整格布局，复制偏移一格；拖动将实际位置吸附到当前网格，多选拖动保留相对距离。旧地图中的半格偏移不会被静默改写，可选中物体后点击「对齐网格」（包括高度，支持撤销）。半格组轴心属于合法旋转中心，不代表构件错位。

3 号旋转机关使用四臂手轮：中空轮毂、四根方杆、末端方块、墙面轴座。属性栏可分别设置主体、轮毂、方杆与轴、末端方块、轴座颜色，并提供三套预设。配色随 JSON 保存。手轮的初始安装方向由局部转轴决定：X/Z 为侧面，Y 为顶部。修改 X/Y/Z 朝向时，平台、轴座和手轮绕路径块中心整体旋转，控制轴也一起转向；目标组绕手轮路径块中心旋转，修改组轴心不会影响手轮。

试玩时按住轮毂或轮臂，围绕手轮在屏幕上的中心转动鼠标或手指，角度跟随绕动，可正反向连续旋转任意圈数，松手按设置吸附，再按住可继续旋转。手轮不设角度上下限，平移机关仍按设置的行程限位。沿半径拖动不改变角度，拖路径平台也不会触发旋转。

旋转视角不会修改地图。选取、放置和错觉接缝按当前相机同步计算；分体方块偏离等轴视角后会分离，复位后重新连接。角色行走与机关动画期间暂停相机旋转，独立地图游戏中的同名按钮使用 Engine GUI。

### 海面与四角立柱

选择 **11 号海面** 后在画面中放置，默认位于当前放置高度下方两格。右栏可调范围、颜色、起伏幅度、速度和波长；编辑与试玩中都会起伏。

选择一段 **1 号普通路径**，再使用 **12 号纤细立柱** 工具，点击该路径四个角的加号逐根放置；也可直接使用路径属性中的四个放柱按钮。同一角点不会重复放柱。立柱可分别调整高度、柱径、颜色及所在角点，并随路径移动、旋转、复制或删除；选择已放置的立柱后仍可继续在其所属路径上放置。

左侧「潮汐回廊 · 手轮与海上立柱」提供可通关示例，也可打开 <http://127.0.0.1:4178/tools/valley-editor/index.html?demo=sea>：将竖起的桥绕手轮转下 90°，再前往出口。海面和立柱会随 JSON 保存。

### 方块与三棱柱的正确关系

选择一个未旋转的单位方块，在右栏点击「拆为 A / B 三棱柱」。它会沿顶面对角线竖直切成两个互补的半块；A 保留原位置，B 沿默认等轴视线偏移，默认从 `[x,y,z]` 移到 `[x+3,y+3,z+3]`。两者拥有独立位置，在默认等轴正交画面中仍拼成一个完整方块。A/B 半块都绕各自所在方块的几何中心旋转；单位方块的轴心在定位锚点下方半格，修改 X/Y/Z 旋转不会让方块中心偏移。这是制作不可能几何时的分体接缝构件。

导出会保存两个 5 号实例、`prismHalf`、各自变换及对角切面连接。半块在不同物体组中也可以独立运动；投影错开或切面朝向不符时，道路断开。拆分是一条可撤销操作。普通方块的六个面和三棱柱的五个面都有独立通路；同一面的边中点经面中心相连，相邻物体的同向表面自动衔接。点击哪个面，就寻路到哪个面。各面之间需要通过扭转路径或带翻面的圆弧衔接。

左侧「分体方块 · 两地拼成一格」可直接观察并试玩，也可打开 <http://127.0.0.1:4178/tools/valley-editor/index.html?demo=split>。该示例只验证分体接缝，不是完整的彭罗斯三角关卡。已有 JSON 中明确设置的非单位尺寸会保留。

### 错觉场景的光照

地图统一保留日光与环境光的面明暗，关闭真实跨物体投影，避免高处平台把阴影投到近处道路、暴露隐藏的深度差。角色脚下使用小范围柔和接触阴影，随角色当前行走面和跨缝位置一起变化；编辑器与独立游戏一致，不改变地图 JSON。接缝附近还会检测角色轮廓的遮挡：若另一半块的斜面提前挡住身体，仅沿正交视线调整人物的显示深度，脚下屏幕坐标保持不变；真实寻路位置及按钮触发不变。只对已对齐的邻近错觉接缝生效，旋转视角仍可检查真实几何，错觉只在接缝对齐的视角成立。

### 旋转接缝与六面通路

「折角回廊」保留用户提供的两个 A 半块位置 `[2,0,2]`、`[7,5,7]` 和旋转 `[90,0,-90]`、`[-90,-90,0]`，无需手写接缝即可通关。实际切面投影互补时，系统会在切面边界连接可行走的表面，包括紧邻半块的普通路径；旋转视角或移开半块会断路。示例地址为 `?demo=seam`。

「翻面之径」（`?demo=surfaces`）展示角色沿 90° 扭转路径进入方块的 Z+ 侧面，然后沿相邻方块侧面到达出口。点击未接通的顶面不会把角色从侧面直接切过去。

「弧光之径」（`?demo=arc`）展示圆弧同时转向与翻面。7 号圆弧的「沿圆弧翻面角度」控制截面从起点到终点的转动，JSON 字段为 `arcTwist`，默认 0，旧地图仍保持平面圆弧。角色的脚和朝上方向跟随曲面变化。

## 物体编号

| type | 构件 | 主要参数 |
| --- | --- | --- |
| 1 | 普通立方体路径 | 一格默认 1×1×1，六面分别可行走 |
| 2 | 楼梯 | 长度、升高、台阶数 |
| 3 | 拖拽旋转机关 | 旋转轴、连续多圈旋转、吸附间隔、目标组 |
| 4 | 拖拽平移机关 | 平移轴、距离范围、吸附间隔、目标组 |
| 5 | 三棱柱半块 | `prismHalf` A/B，互补直角三角顶面，体积各半 |
| 6 | 扭转路径 | 矩形截面、扭转角；角色朝向沿曲面变化 |
| 7 | 圆弧路径 | 半径、圆心角、翻面角度、宽度、厚度 |
| 8 | 踩踏开关 | 触发方式、一个或多个组动画 |
| 9 | 出生平台 | 角色初始位置 |
| 10 | 出口平台 | 通关目标 |
| 11 | 海面 | 范围、颜色、起伏幅度、速度、波长 |
| 12 | 纤细立柱 | 路径四角依附、高度、柱径、颜色 |

编号由 `catalogVersion: 1` 固定；每个实例另有唯一字符串 `id`。机器可读目录、JSON Schema 和示例在 `games/valley-of-light/maps/`。格式细节见 `games/valley-of-light/map/FORMAT.md`。

## Editor 与运行时的分工

- `ValleyAuthoring` 使用公开的 `@haiyue/editor-platform` 文档、事务历史、选择系统及插件贡献；`@haiyue/editor-shell` 管理面板贡献和快捷键。导入/导出器通过 SDK 注册。
- Editor 面板使用浏览器 DOM。地图视口由 Haiyue Engine 渲染。独立游戏 HUD 使用 Engine GUI，角色通过 Extensions glTF 插件加载 Idle/Walk 动画。
- 编辑器与游戏共享 `map/model.ts` 的校验、参数化路径、连通图和确定性动画，及 `map/view.ts` 的渲染。游戏不依赖 Editor。
- Editor 依赖是 `vendor/` 中的公开发布包：Platform 0.1.0、Plugin SDK 0.1.0、Shell 0.1.1、UI 0.1.3；来自工作区已发布的包归档。没有导入 Editor/AIStudio 私有实现或相邻仓库源码。
- 当前是桌面地图工坊：可旋转正交视角，最多 500 个物体；存储方式为手动导出 JSON。试玩不写入地图或游戏存档。

## 验证

在 Games 根目录：

```powershell
npm --prefix tools/valley-editor run typecheck
npm --prefix tools/valley-editor test
node --experimental-strip-types --test games/test/valley-map.test.mjs games/test/valley-surfaces.test.mjs games/test/valley-wheel-drag.test.mjs
node tools/valley-editor/verify-browser.mjs
node tools/valley-editor/verify-player.mjs
node tools/valley-editor/verify-split.mjs
node --experimental-strip-types tools/valley-editor/verify-prism-picking.mjs
node tools/valley-editor/verify-surfaces.mjs
node tools/valley-editor/verify-orbit-wheel.mjs
node tools/valley-editor/verify-placement.mjs
node tools/valley-editor/verify-grid-orientation.mjs
node tools/valley-editor/verify-seaside.mjs
node tools/valley-editor/verify-seaside-player.mjs
```

最后十项需要相邻 Engine 仓库的浏览器验证工具以及本机 Chrome。先运行编辑器验证，生成实际导出的 JSON，再运行独立游戏验证。分体方块验证会检查一键拆分、撤销、导出、错位断路，以及角色跨越两个不同深度的半块。潮汐回廊验证检查海面实际画面变化、逐角放柱、撤销重做、手轮轴向和屏幕绕转、手轮路径轴心与组轴心的区别，以及独立游戏中的真实触屏转轮和 GUI 通关。先运行 `verify-seaside.mjs` 导出地图，再运行 `verify-seaside-player.mjs`。截图与日志输出到 `artifacts/valley-editor/`。调试快照仅在 `?verify=1` 时提供，且没有改变地图或角色的接口。
