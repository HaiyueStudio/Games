# 谷外之光 · 地图工坊

使用 Haiyue Editor 公开能力制作正交几何解谜地图，输出可直接在《谷外之光》中加载的 JSON。包含十七种标准构件、参数编辑、物体组、踩踏开关、错觉接缝和即时试玩。

## 启动

先在 Games 根目录安装项目依赖；Node.js 22+，浏览器需要 WebGPU。然后在 Games 根目录运行：

```powershell
npm --prefix tools/valley-editor install --offline --ignore-scripts
npm run build:valley-editor
npm run build:target -- game:valley-of-light
npm run editor:valley
```

也可以进入 `tools/valley-editor` 后执行 `npm run serve`。打开 <http://127.0.0.1:4178/> 会自动跳转到编辑器；完整地址为 <http://127.0.0.1:4178/tools/valley-editor/index.html>。根地址及目录地址的跳转会保留 `?demo=sea` 等参数。端口可通过 `node tools/valley-editor/serve.mjs 4180` 指定。服务器同时提供 Games 文件，游戏地址为 <http://127.0.0.1:4178/games/valley-of-light/index.html>。

## 制作地图

界面使用 Haiyue UI 的 Button、Input、Select、Dialog、Tree、Context Menu、Tabs 与 Split Web Components。标准物体和地图层级并排显示，目录通过标签页切换「路径」和「装饰物」。左右侧栏、左侧两栏之间和右侧上下区域的分隔线均可拖动；分隔线聚焦后也支持方向键调节。目录/示例、地图层级、属性和物体组区域分别滚动，场景随面板大小实时适配。面板比例自动保存在当前浏览器中，底部「重置面板」可恢复默认；布局调整不影响地图内容或撤销历史。JSON 多行编辑框和文件选择器保留浏览器原生控件。

1. 点击左侧构件，再在视口中按下并松手放置；按住移动时只预览，松手后才生成一个物体。普通路径默认是 1×1×1 方块，默认按 1 格吸附。像搭方块一样，点击已有道路的顶面向上叠放、底面向下叠放、侧面向外续接；以鼠标命中的实际表面为准，轮柄、旗杆、出口装饰不会改变贴面位置。悬空道路和旋转后的道路按实际表面贴邻放置，预览显示目标高度，红色表示目标格已占用。空白处靠近道路边缘仍可自动续接；从道路拖向更远的空处会保持最近预览的放置高度。直接在空白处放置使用工具栏的编辑高度与吸附间隔，海面仍按编辑高度放置。Esc 或移出画布后松手取消本次放置；按 Esc 回到选择工具。
2. 拖动物体在 XZ 平面移动。右栏可精确编辑位置、旋转、长宽厚，以及楼梯级数、扭转角、圆弧半径和角度。点击按实际模型表面选中最前方物体，三棱柱的顶面、底面和侧面均可选中，空缺半块不会误选。选中物体显示金色包围盒线框，材质和配色保持原样。多选分别显示包围盒，选择父节点显示包含全部子构件的整体范围，空节点显示小框；线框随拖动、旋转、缩放和撤销更新，试玩时隐藏，不参与拾取或导出。场景不显示物体名称标签，名称在层级和属性栏查看。网格交点对应路径中心锚点，网格随编辑高度和吸附间隔变化，X/Z 轴以不同颜色标出；右上「网格」可切换显示，试玩时自动隐藏。右键或中键拖动画面，滚轮缩放。点击视口右上「旋转视角」后左键拖动；「复位等轴视角」恢复初始投影。
3. 地图层级使用 Haiyue UI 的 Tree 组件。Ctrl 点选或 Shift 范围多选后点击「成组」，生成并选中父节点；右栏可编辑父节点的位置、旋转、缩放，统一影响所有子节点。父节点可以嵌套，编组和换父节点保持物体当前世界位置。右键节点或层级空白处可创建空节点、复制、剪切、粘贴、复制副本、移至根层和删除。拖入父节点收纳构件，拖到节点上下边缘调整顺序；也可在属性中选择父节点。选中父节点后放置构件，会自动放入其中。
4. 放置 **8 号踩踏开关**，添加目标组动作，填写目标位移、旋转、时长和缓动。一个开关可同时控制多个组；支持一次触发与重新踩入切换。
5. 三维位置相同且表面朝向一致的道路端点自动相连。三棱柱按实际旋转后的切面与投影自动匹配，不要求一定是一个 A 和一个 B。其他道路要制作视觉错觉时，Shift 选中两段道路，在「错觉接缝」中指定 A/B 端点。只有它们在当前正交视角中对齐时，角色才能跨越真实空间的间隔。
6. 选择 **9 号出生记号**和 **10 号出口记号**，分别点击已有普通路径的表面添加，点击「试玩地图」。点击道路让角色行走，按住 3 号手轮绕其屏幕中心转动，或拖拽 4 号平移机关。手轮不可操作时自动收起轮臂，可操作时展开；行走、站在受控道路上、开关动画与通关都会同步禁用状态，收放保留旋转角度。停止试玩后恢复编辑时的初始地图。
7. 「精简导出」下载省略默认值的 v2 JSON，并保存静态合并计划；「导入 JSON」支持完整 v1 和精简 v2，均可继续编辑。「查看 JSON」保留可读的完整数据，支持修改应用及下载两种格式。所有结构修改，包括导入，都可撤销。

快捷键：Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 重做，Ctrl/Cmd+D 复制，Delete 删除。输入框获得焦点时保留原生文本编辑行为。一次拖拽只产生一条撤销记录；Esc、失去焦点和画布尺寸改变会取消尚未提交的拖动。

默认「开关花园」是一关可通关示例：先踩左边按钮，将两段桥一起移入道路；再走向第二个按钮，转正最后的回廊；最后点击出口。「物体目录」用于查看编号构件，未连接成完整关卡。

### 整格对齐与机关配色

普通方块、机关平台的锚点统一为顶面中心。示例构件按整格布局，复制偏移一格；拖动将实际位置吸附到当前网格，多选拖动保留相对距离。旧地图中的半格偏移不会被静默改写，可选中物体后点击「对齐网格」（包括高度，支持撤销）。半格组轴心属于合法旋转中心，不代表构件错位。

3 号旋转机关使用四臂手轮：中空轮毂、四根方杆、末端方块、墙面轴座。属性栏可分别设置主体、轮毂、方杆与轴、末端方块、轴座颜色，并提供三套预设。配色随 JSON 保存。手轮的初始安装方向由局部转轴决定：X/Z 为侧面，Y 为顶部。修改 X/Y/Z 朝向时，平台、轴座和手轮绕路径块中心整体旋转，控制轴也一起转向；目标组绕手轮路径块中心旋转，修改组轴心不会影响手轮。

试玩时按住轮毂或轮臂，围绕手轮在屏幕上的中心转动鼠标或手指，角度跟随绕动，可正反向连续旋转任意圈数，松手按设置吸附，再按住可继续旋转。手轮不设角度上下限，平移机关仍按设置的行程限位。沿半径拖动不改变角度，拖路径平台也不会触发旋转。

试玩时行走途中可以再次点击道路，从当前路段切换目标或掉头；拐角、圆弧、扭转与错觉接缝仍沿合法通路行走。点击不可达表面会提示未连通，并保留当前路线；开关动画期间暂停新的行走指令。

旋转视角不会修改地图。选取、放置和错觉接缝按当前相机同步计算；分体方块偏离等轴视角后会分离，复位后重新连接。角色行走与机关动画期间暂停相机旋转，独立地图游戏中的同名按钮使用 Engine GUI。

### 建筑与花木

在「装饰物」标签页选择 13～16 号构件，点击道路实际表面放置，悬空道路会沿用命中表面的高度；空白处按编辑高度放置。底部中心为定位和旋转原点，可单独调整长、宽、高及各部位颜色。装饰物不参与寻路，可以编组、复制和撤销；完整与精简 JSON 都保存尺寸、变换与配色。旗帜使用弯曲飘带造型。每件装饰物按颜色合并几何，不为每片叶面或花瓣创建单独网格。

「花园塔影 · 建筑与花木」提供配色和摆放示例，也可打开 `?demo=decorations`。海面和立柱同样位于「装饰物」标签页。

### 海面与四角立柱

选择 **11 号海面** 后在画面中放置，默认位于当前放置高度下方两格。海面由不规则三角切面组成，右栏可设置主色、亮面色、暗面色、切面大小、明暗对比，以及起伏幅度、速度和波长；提供碧海、落日、暮紫三套配色。未指定亮暗色时自动跟随主色，也可点击按钮恢复跟随。编辑与试玩中都会起伏；每片海面使用一个网格，波浪由 GPU 更新。

选择 **1 号普通路径**（包括带出生记号的路径，兼容旧 9 号平台），再使用 **12 号纤细立柱** 工具，点击该路径四个角的加号逐根放置；也可直接使用路径属性中的四个放柱按钮。新放置的立柱沿路径局部 X/Z 方向各向内缩进 0.1 格（单位方块落点为 ±0.4），角点加号与实际落点一致；已保存的立柱位置保留。同一角点不会重复放柱。立柱可分别调整高度、柱径、颜色及所在角点，并随路径移动、旋转、复制或删除；选择已放置的立柱后仍可继续在其所属路径上放置。

左侧「潮汐回廊 · 手轮与海上立柱」提供可通关示例，也可打开 <http://127.0.0.1:4178/tools/valley-editor/index.html?demo=sea>：将竖起的桥绕手轮转下 90°，再前往出口。海面和立柱会随 JSON 保存。

### 梯子路径

「路径」目录中的 **17 号梯子路径** 可连接上下平台。点击墙面或平台顶面靠近边缘的位置，会贴着该侧放置，默认从上沿向下延伸两格。空白处以当前编辑高度作为梯脚高度。右栏可以修改梯宽、爬升高度、横档间隔数、梯框与横档颜色；修改 Y 旋转可改变贴墙方向。

未旋转时墙面在局部 Z=0，梯子朝向 Z+：下层道路端点需对齐 `[0,0,0.5]`，上层端点对齐 `[0,rise,0]`。角色上、下梯时面朝墙壁播放 Climb 动作，中途可以点击道路掉头。每架梯子的梯框和横档按颜色合成两个网格。左侧「攀光庭院 · 沿梯而上」（`?demo=ladder`）可直接试玩，独立游戏可加载 `maps/ladder-garden.json`。

### 方块与三棱柱的正确关系

选择一个未旋转的单位方块，在右栏点击「拆为 A / B 三棱柱」。它会沿顶面对角线竖直切成两个互补的半块；A 保留原位置，B 沿默认等轴视线偏移，默认从 `[x,y,z]` 移到 `[x+3,y+3,z+3]`。两者拥有独立位置，在默认等轴正交画面中仍拼成一个完整方块。A/B 半块都绕各自所在方块的几何中心旋转；单位方块的轴心在定位锚点下方半格，修改 X/Y/Z 旋转不会让方块中心偏移。这是制作不可能几何时的分体接缝构件。

导出会保存两个 5 号实例、`prismHalf`、各自变换及对角切面连接。半块在不同物体组中也可以独立运动；投影错开或切面朝向不符时，道路断开。拆分是一条可撤销操作。三角面经过时直接连接入口与出口，避免拼合直路上的重心绕行；普通方块的六个面和三棱柱的五个面都有独立通路；同一面的边中点经面中心相连，相邻物体的同向表面自动衔接。点击哪个面，就寻路到哪个面。各面之间需要通过扭转路径或带翻面的圆弧衔接。

左侧「分体方块 · 两地拼成一格」可直接观察并试玩，也可打开 <http://127.0.0.1:4178/tools/valley-editor/index.html?demo=split>。该示例只验证分体接缝，不是完整的彭罗斯三角关卡。已有 JSON 中明确设置的非单位尺寸会保留。

### 错觉场景的光照

地图统一保留日光与环境光的面明暗，关闭真实跨物体投影，避免高处平台把阴影投到近处道路、暴露隐藏的深度差。角色脚下使用小范围柔和接触阴影，随角色当前行走面和跨缝位置一起变化；编辑器与独立游戏一致，不改变地图 JSON。接缝附近还会检测角色轮廓的遮挡：若另一半块的斜面提前挡住身体，仅沿正交视线调整人物的显示深度，脚下屏幕坐标保持不变；真实寻路位置及按钮触发不变。只对已对齐的邻近错觉接缝生效，旋转视角仍可检查真实几何，错觉只在接缝对齐的视角成立。

### 旋转接缝与六面通路

「折角回廊」保留用户提供的两个 A 半块位置 `[2,0,2]`、`[7,5,7]` 和旋转 `[90,0,-90]`、`[-90,-90,0]`，无需手写接缝即可通关。实际切面投影互补时，系统会在切面边界连接可行走的表面，包括紧邻半块的普通路径；旋转视角或移开半块会断路。示例地址为 `?demo=seam`。

6 号扭转路径绕截面中心旋转，中轴保持直线，两端不会因厚度产生斜向偏移；行走面和接缝端点随实际外表面同步变化。单位厚度转过 90° 后，末端行走面位于中轴的 Z+ 侧，可连接相邻方块的侧面。 点击扭转或圆弧的端面续接平台时，使用该端面的真实通行端点和翻面方向，端面上的鼠标落点不改变平台位置；续接的普通路径也随行走面转向，然后可在它的表面添加出生/出口记号。空白处续接使用道路中轴方向，不使用扭转表面的螺旋切线。以前已保存的偏移位置会保留，需要重新贴端面放置或导入修正地图。

「翻面之径」（`?demo=surfaces`）展示角色沿 90° 扭转路径进入方块的 Z+ 侧面，然后沿相邻方块侧面到达出口。点击未接通的顶面不会把角色从侧面直接切过去。

「弧光之径」（`?demo=arc`）展示圆弧同时转向与翻面。7 号圆弧的「沿圆弧翻面角度」控制截面从起点到终点的转动，JSON 字段为 `arcTwist`，默认 0，旧地图仍保持平面圆弧。角色的脚和朝上方向跟随曲面变化。

### 层级与剪贴板

- `Ctrl+C / Ctrl+X / Ctrl+V` 复制、剪切、粘贴；`Ctrl+D` 在旁边创建副本。剪切在粘贴时才移动来源，保留 ID。复制整个父节点会复制所有子节点、依附立柱、内部接缝和机关引用；副本的机关指向副本内部对应的组。
- 粘贴到所选父节点中；选择普通构件时粘贴到它的同级。右键层级空白处再粘贴，会放到地图根层。粘贴保留原世界位置，重合时可直接调整新父节点的位置。
- 删除父节点会一起删除子节点，并清理其他开关对已删除组的引用；整次操作支持撤销、重做。
- 开关旋转轴心使用节点内坐标，手轮仍围绕自身路径块中心驱动目标节点及其所有后代。

## Editor 与运行时的分工

- `ValleyAuthoring` 使用公开的 `@haiyue/editor-platform` 文档、事务历史、选择系统及插件贡献；`@haiyue/editor-shell` 管理面板贡献和快捷键。导入/导出器通过 SDK 注册。
- Editor 面板使用浏览器 DOM。地图视口由 Haiyue Engine 渲染。独立游戏 HUD 使用 Engine GUI，角色通过 Extensions glTF 插件加载 Idle/Walk/Climb 动画。
- 编辑器与游戏共享 `map/model.ts` 的校验、参数化路径、连通图和确定性动画，及 `map/view.ts` 的渲染。游戏不依赖 Editor。
- Editor 依赖是 `vendor/` 中的公开发布包：Platform 0.1.0、Plugin SDK 0.1.0、Shell 0.1.1、UI 0.1.3；来自工作区已发布的包归档。没有导入 Editor/AIStudio 私有实现或相邻仓库源码。
- 当前是桌面地图工坊：可旋转正交视角，最多 500 个物体；存储方式为手动导出 JSON。试玩不写入地图或游戏存档。

## 静态渲染优化

试玩和独立游戏会自动合并同材质的静态道路，删除轴对齐方块的内部贴合面并合并共面矩形。机关驱动的组（包含嵌套子组与依附立柱）、按钮、海面保持动态。编辑状态保留逐个选择高亮，停止试玩可继续编辑。后台 Worker 计算几何，地图切换时取消；静止帧不重复计算地图变换。

精简导出保留参数化构件及原始精度，加载时再生成网格，避免在 JSON 里写入大量顶点。完整格式与精简格式可相互导入/导出，不改变层级或通路。

局部回归与真实浏览器性能对比：

```powershell
node --experimental-strip-types --test games/test/valley-static.test.mjs
node --experimental-strip-types tools/valley-editor/verify-performance.mjs
node --experimental-strip-types tools/valley-editor/verify-retarget.mjs
node --experimental-strip-types tools/valley-editor/verify-straight-split.mjs
node --experimental-strip-types tools/valley-editor/verify-wheel-state.mjs
```

`verify-performance.mjs` 使用同一份精简地图，在编辑器试玩和独立游戏分别对比正常合并与 `?batch=0` 诊断基线，记录引擎实际 draw call、网格/三角形和静止帧变换复用，验证合并后的单块点击行走及停止试玩恢复编辑。结果为 `artifacts/valley-editor/static-performance.json`，同时保留前后截图。`?verify=1` 调试快照新增只读 `performance` 和 `diagnostics`。

2026-10-08 的 10×10 同材质方块样例：静态网格 100→1、三角形 1200→12；试玩整场 draw call 120→21，游戏 122→23（含角色/出生与出口/GUI）。地图完整缩进格式 94,444 字节，去缩进后 51,159 字节，精简格式 5,130 字节。收益取决于地图布局与动态对象比例，不代表所有地图的固定帧率提升。

`verify-straight-split.mjs` 验证出生平台的画布/属性放柱、0.1 格内缩、撤销和精简导入，并逐帧记录编辑器与独立游戏跨越分体方块的往返路线，断言投影始终在同一直线上。

`verify-wheel-state.mjs` 检查编辑器和独立游戏的手轮收放中间帧、嵌套组占用锁定、禁用点击/拖动、原有旋转角度保留、恢复后的整圈转动，以及开关动画和通关时的状态。

装饰物与并排目录局部验证：`node --experimental-strip-types --test games/test/valley-decorations.test.mjs`、`node --experimental-strip-types tools/valley-editor/verify-decorations.mjs`、`node tools/valley-editor/verify-ui.mjs`。


扭转路径在试玩和独立游戏中按长度每 1 格提供一个停靠位置，例如长度 5 有 5 个位置；末尾不足 1 格时取剩余段中心。点击按所在格选择，行走中再次点击可以改道或返回。路径点击会在目标位置播放 1 秒的贴面亮点，连续点击重启提示，退出试玩或重开地图立即清除。

局部验证：`node --experimental-strip-types --test games/test/valley-twist-stops.test.mjs`、`node tools/valley-editor/verify-twist-stops.mjs`（编辑器试玩及独立游戏）。


## 路径记号与门

9 / 10 号是贴记号的工具：点击已有普通路径的目标表面，不增加新的方块。右侧「路径记号」可选择无、出生点、出口，以及所在面；出生记号移到新路径时自动清除原记号。移动、旋转和编组都会带着记号一起变化，支持撤销与完整/精简导出。复制带出生记号的路径时，保留原出生点，副本成为普通路径。旧地图的 9 / 10 号平台仍能加载，按普通路块加记号显示；旧出口不再自动生成门。

18 / 19 号拱门和方门位于「装饰物」中，有实际门洞，可以自由放置在路径上，修改长宽高、旋转及部位配色。门与出口逻辑独立，出口记号本身就能触发通关。

6 号扭转角度支持 ±36000°，例如 720°、1080°；采样随圈数增加，单步翻面不超过 7.5°，每格停靠和端点衔接保持一致。示例「回旋门廊」也可通过 `?demo=gates` 打开。

局部验证：`node --experimental-strip-types --test games/test/valley-markers-gates.test.mjs`、`node tools/valley-editor/verify-markers-gates.mjs`。
