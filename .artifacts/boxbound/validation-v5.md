# Boxbound 上下台阶动画验证

本地诊断证据，工作区有未提交修改，不是正式发布基准。动画修订为 5，游戏规则及存档版本仍为 4。最终构建、源码及截图指纹见 `validation-v5.json`。

- 上台阶或盒顶时先垂直抬升，身体高于顶面后再横移，最后落稳；下台阶先保持高度移出边缘，再垂直落地。
- 高差移动使用 420 毫秒动画，普通步行仍为 160 毫秒。连续输入缓存一个后续动作，避免新输入截断尚未落地的动画；重复移动不会覆盖已缓存的跳跃。
- 通关庆祝等到落地后开始，准备动作只压缩身体，不把脚底压入支撑面。盒顶微缩地图限制为浅浮雕，避免内部高处摆件与站在盒顶的角色重叠。
- 每毫秒采样四个方向、不同起跳高度的身体包围范围，检查上升和下降跨越边缘时的净空；同时检查轨迹连续性、多格下落和精确落点。
- 浏览器真实键盘事件验证上升、越边、下降、落地和快速反向输入。固定动画时钟并等待实际渲染帧，另保存 `climb-1440.png` 与 `descent-1440.png` 中间帧截图。

检查结果：

- `npm run typecheck` 通过；最终 Boxbound 独立 TypeScript 检查与 ESLint 通过。
- Boxbound、存档及预览相关测试 48 / 48 通过。
- `GAME_FILTER=boxbound GAME_BUILD_TIMEOUT_MS=180000 npm run build` 通过。
- 最终 `node scripts/verify-boxbound.mjs`：10 / 10 场景、295 条浏览器断言通过，WebGPU 错误为 0；所有截图与最终 bundle 指纹一致。已人工查看上升越边与下落中间帧，身体与盒体无穿插。

全库执行 `npm test -- --test-concurrency=2`，共 852 项：821 通过、2 失败、9 超时取消、20 跳过。失败位于本次未修改的 HYMUGEN 指纹与 MUGEN 虚拟列表断言；9 个本地 Petra 案例超时。没有修改、跳过这些用例或放宽测试阈值。全库运行开始于最后一次盒顶浅浮雕微调之前，最终独立类型检查、ESLint、构建和浏览器验证覆盖了该微调。其他任务的 led-sudoku 修改保持原样。
