# Boxbound 压力按钮与铁栅栏验证

本地诊断证据，不是正式发布基准。渲染修订为 7、存档规则版本为 5；最终源码、构建和截图指纹见 `validation-v7.json`。

- `Room.buttons` 与 `Room.gates` 按同一房间的 `channel` 联动。角色的落脚格或箱子底面覆盖按钮时持续供能，同组任意按钮按下即可开门，不同房间互不干扰。
- 未供能时铁栅栏阻挡步行、推箱和跳上栅栏顶。门洞内仍有角色或箱子时保持降下，通道清空后重新升起，避免夹住或产生无效重叠状态。开闭状态由当前实体位置推导，不保存容易过期的开关缓存。
- 圆形按钮使用 Haiyue 公共圆柱几何 API；按钮下压、铁栅栏下沉/升起使用 320ms 动画。按下后按钮与门柱指示灯变为薄荷绿。普通撤销、载入和场景切换恢复对应状态。
- 大世界入口已有一组可玩的机关：圆形按钮、联动铁栅栏及金色压重箱。十个原有关卡保留原有解法。帮助和世界提示说明操作与占用保护。
- 旧存档升级到规则版本 5，只添加群岛机关；保留步数、完成进度、空间路径和已经运出的箱子。与新增围墙冲突的角色、箱子移到安全位置，地面箱子保持在地面；不会复制已有压重箱。

验证内容：

- 独立 Boxbound 测试 52 / 52 通过，涵盖角色与箱子触发、压力交接、大箱子底面、松开复位、门洞占用保护、关闭时碰撞、跨房间隔离、多按钮联动、五槽存档、旧存档迁移和无效配置拒绝，并保留十关解法回归。
- `npm run typecheck`、Boxbound 独立 TypeScript 检查、ESLint 与正式游戏构建通过。
- 浏览器通过真实键盘操作验证踩下、离开、推箱压住、保存、撤销、通行保护和重新阻挡，使用固定动画时钟与实际渲染帧。已人工查看 `pressure-open-1440.png` 与 `pressure-closed-1440.png`，确认圆形按钮、金色箱子及升降铁栅栏的实际画面。
- 最终浏览器 15 / 15 场景、491 条断言通过，WebGPU 错误为 0；所有截图绑定同一个最终构建。完整结果与全库测试计数见同名 JSON。

全库测试启动时保留了一版待修正的占用保护测试路径：它试图把箱子继续推入第 8 关的固定窄门，因此按正确碰撞规则被拒绝。测试路径已改为推离栅栏后退开并离开按钮，保持原有占用保护与关门断言；修正后的 52 项相关测试全部通过。全库日志仍记录修正前的这一项失败，其他模块的失败和超时另记于 JSON；没有放宽碰撞规则或测试阈值。
