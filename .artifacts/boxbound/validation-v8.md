# Boxbound 动画撤销与出口外墙验证

本地诊断证据，不是正式发布基准。渲染修订 8、存档规则版本 5；源码、构建和截图 SHA-256 见 `validation-v8.json`。

- 历史快照保存该步跳跃和箱子跨界轨迹。撤销通过同一渲染管线反向移动角色、箱子和机关，跨界箱子反向缩放，跨房间回退使用镜头过渡。
- 动作尚未完成时撤销按顺序等待，连续撤销逐步执行；重玩布局的撤销使用遮罩过渡，避免箱子跨越任意墙体。回退完成状态不会重复触发通关庆祝。
- 出口外墙和关闭栅栏由当前路径中的实际盒子及其当前位置推导，使用与规则相同的出口坐标。共享空间、自引用空间不会产生无限展开，不向内部地图写入外部墙体，可推动箱子不会被误识别为墙。
- 外墙模型位于对应出口外侧，使用相同石材、圆角与浅色凸点，内部四向通道保持原有几何；外层栅栏供能开启后不会显示关闭的栏杆。

验证结果：

- Boxbound 规则测试 56 / 56 通过，保留十关解法、压力机关与存档回归，新增四向外墙、共享空间实际入口、移动容器、自引用、关闭栅栏与可移动箱子区分、跨界轨迹反向还原测试。
- TypeScript、Boxbound ESLint 与正式构建通过，`git diff --check` 通过。
- Chrome WebGPU 浏览器 18 / 18 场景、602 条断言通过，GPU 错误和未分类浏览器错误为 0；每张截图绑定最终构建哈希。
- 新增真实键盘验证：推箱撤销中间帧、连续三步撤销含高度变化、箱子反向放大、按钮与栅栏回退、实际进入第六关深层小房间并显示东/南两侧外墙、跨场景撤销镜头及还原路径。
- 已目视检查 `undo-step-1440.png`、`undo-box-1440.png`、`outer-wall-1440.png`，确认撤销中间位置、箱子缩放和两处出口外墙的实际画面。
- 全库测试：879 项，848 通过、2 失败、9 取消、20 跳过。其他模块失败/超时明细见 JSON；Boxbound 相关测试无失败，未修改其他游戏来绕过全库失败。
