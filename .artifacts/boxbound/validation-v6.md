# Boxbound 跨房间推箱与墙体圆角验证

本地诊断证据，工作区有未提交修改，不是正式发布基准。渲染修订为 6，游戏规则存档版本保持 4。最终源码、构建及截图指纹记录于 `validation-v6.json`。

- 角色从四边出口离开时，会尝试推动门外箱子；外层有空位就可以继续推，外层推箱链也遵循碰撞判定。箱子跨界输出时，同样可以推动出口外的箱子。碰到墙、固定箱子或无法移动的推箱链时，整个事务撤回，不留下半完成移动或动画事件。
- 成功的规则事务输出临时跨界事件，包含箱子、容器、方向与内外坐标；这些事件不写入存档。推入动画先缩小再移入门洞，推出动画先离开门洞再放大。过渡时长为 640ms，尺寸取自内外空间比例；内部视角的外部投影限制到 2.5 倍，离开视野的实体末段淡出。输入衔接、撤销及场景切换沿用现有生命周期。
- 墙体外露边缘使用圆角和浅色顶盖，连续段与转角间增加重叠连接段，避免连接处留下圆角凹缝；窄门直接延伸墙段，不附加方形细条。碰撞体素、门宽及墙顶凸点规则不变。
- 新增四方向连续推出、外层推箱链、失败撤回、跨界事件坐标、缩放/移动顺序和直线/L/T 形墙缝检查。浏览器使用真实键盘验证推入、推出、再次出门推动、被挡拒绝与撤销，记录三个新增动画视角。

检查结果：

- `npm run typecheck`、最终 Boxbound 独立 TypeScript 检查和 ESLint 通过。
- `node --experimental-strip-types --test games/test/boxbound.test.mjs`：45 / 45 通过，包含十关完整解法、存档和原有动画测试。
- `GAME_FILTER=boxbound GAME_BUILD_TIMEOUT_MS=180000 npm run build` 通过。
- 最终 `node scripts/verify-boxbound.mjs`：13 / 13 个场景、415 条浏览器断言通过，WebGPU 错误为 0。全部截图绑定同一个最终构建；结果与截图指纹见同名 JSON。人工检查了缩小中的箱子、出口放大过程、外层门口视角和圆角墙体。

全库 `npm test -- --test-concurrency=2` 共 868 项：837 通过、2 失败、9 超时取消、20 跳过。两项失败为本次未修改的 HYMUGEN 指纹和 MUGEN 虚拟列表断言，9 项超时为本地 Petra 案例；没有修改、跳过这些用例或放宽阈值。全库执行开始于最后一次截图采样时刻调整之前，最终独立类型检查、ESLint、构建和浏览器验证覆盖最终版本。其他任务的工作区修改保留原样。
