# Hull-specific animated parts

Fourteen individual sprites generated with the built-in image_gen tool; prompts.json contains the full prompts and provenance.json binds every delivered PNG to its SHA-256. Generated alpha is preserved unchanged. Root part-*.png files are source masters; pack-sky-sprites.py resizes only the runtime RGBA slices to 96–192 pixels.

Dreadnought: heavy plasma turret. Ion Seraph: counter-rotating ceramic impellers. Void Mantis: hinged scythes. Carrier: sliding hangar shutters tied to deployment cadence. Helios: oscillating optical iris. Twins: paired, oppositely rotating gyroscopes with red/blue tint. Mining vessel: drive gear. Elites: crimson railgun, violet capacitors, prism aperture leaves, and separating fission armor. Serpent: layered vertebra armor, hydraulic couplings and independently aimed dorsal guns. Quantum battleship keeps its six existing independent turrets and has no central rotor; health is now 3570.
