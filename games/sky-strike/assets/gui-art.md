# Sky Strike sci-fi GUI art

Generated with the built-in image_gen tool, 2026-09-10. These are project assets, used by Engine GuiImage with live GuiButton text and input. No DOM controls or extra display canvas.

## Assets

- `gui-launch.png`: transparent launch/resume skin. GuiImage crops transparent padding via UVs; labels remain live.
- `gui-arrow.png`: transparent left-arrow housing. The right button uses mirrored GPU UV coordinates, retaining identical material and lighting.
- `gui-pause-panel.png`: opaque purple-glass dialog panel. The rejected checkerboard-background drafts are not used.

`sprites.rgba` and `sprites.json` are reproducibly generated by `Games/scripts/pack-sky-sprites.py` (Python + Pillow). Source PNG alpha is preserved. Buttons have 48–64 point arrow hit targets and independent press/hover tint feedback.
