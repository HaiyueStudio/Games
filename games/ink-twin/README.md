# 墨白双生 · Ink Twin

灰色宣纸上的双线数字解谜。黑白两条线分别从同色的 1 起笔，各自依次经过同色数字。两笔独立操作，路线可以长短不同、布局不对称。只能上下左右行笔，不可相交、重叠，也不能经过另一色的数字；两线均到达各自最后一个数字，并共同铺满全部格子才通关。

- 入墨 6×6、行笔 8×8、化境 10×10；每日关卡按本地日期和难度固定，练习可连续换题。
- 鼠标、触屏和手柄均可拖动任意一色；在线条上重新落笔可以回退。方向键按屏幕方向移动当前线，空格或墨白按钮切换执笔颜色，Z 只撤销当前线、H 提示、R 重开。
- 线条以湿润笔尖连续延伸，快速拖动时平滑追上目标；收笔、重开和换题会清除旧动画。最后一笔延伸完毕才显示通关，减少动态效果偏好下即时呈现。
- 使用仓库统一的引擎单槽自动存档，保存黑白两条路线、执笔颜色、计时和提示次数。独立双线使用版本 2 格式，原旋转同步版本的旧局不继续沿用。
- 提示使用生成时的完整可解路线；有分歧时保留两条线的可行前缀，明确告知并收回岔路，再为当前颜色续一格；当前线完成时自动提示另一色。不要求答案唯一。
- `rules/model.ts` 是无 DOM 的确定性规则；构造关卡使用有界的 Hamiltonian backbite 变换，再分为两条长短不同的连续路径，各自放置数字，保证完整覆盖且可解。
- 数字使用生成的透明水墨 bitmapfont 图集，运行时按同一 alpha 分别着墨黑、白；`art/InkBoardArt.ts` 绘制渗墨、笔锋和飞白。背景为生成的灰色宣纸纹理。
- `art/strokeReveal.ts` 记录两支笔的可见距离；`rendering/BoardView.ts` 在引擎帧中推进生长，只在墨迹变化时上传纹理。通过公开引擎接口和实验性 `RenderIntegration` 呈现，引擎负责 WebGPU 提交、游戏大厅挂载和资源回收。

```sh
npm run build:target -- game:ink-twin
node --experimental-strip-types --test games/test/ink-twin.test.mjs
node games/ink-twin/verify-browser.mjs
```

通过仓库 HTTP 开发服务访问 `games/ink-twin/index.html`，或在游戏大厅选择「墨白双生」。浏览器验证输出位于 `artifacts/ink-twin/`，包含桌面、触屏竖屏、双笔行迹和通关截图。
