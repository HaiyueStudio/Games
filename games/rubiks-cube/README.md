# 魔方实验室

WebGPU 三维魔方，二阶、三阶、四阶及偏心切割的三阶镜面魔方。所有菜单、按钮、文字均由 Engine `GuiSystem` 绘制；浏览器仅提供画布和启动错误提示。Native 共享相同规则、场景、GUI 和输入逻辑。

小块本体与面片使用 Engine `createRoundedBox3D` 圆角几何，镜面块按实际尺寸生成圆角；相同尺寸复用几何。本体间隙为 0.0275、面片间隙为 0.06，均为最初版本的一半。相机采用 45° 透视投影，横竖屏自动调整观察距离与中心位置，为 HUD 留出空间。

- 首页选择魔方；拖动方块表面转动对应层，拖动空白区域环绕观察。
- 按 X / Y / Z 选轴，按编号选层，再按正转或反转。层从负方向到正方向编号：L→R、D→U、B→F；四阶的两层内层均可独立操作。正转遵循对应正轴的右手规则。
- 打乱生成合法随机单层操作（二阶 16 步，三阶/镜面 25 步，四阶 40 步）。为练习而设计，不是比赛用均匀随机状态打乱器。
- 每个完成的四分之一圈记为一步，包括打乱。撤销只退一步；还原逐步逆序回放全部记录，直到本局初始状态。停止会完成当前动画后停下，记录始终与画面一致。旋转途中禁止混入其他操作。
- 首页重新选型开启新局；后台暂停保留内存中的本局，冷启动记住上次选择的魔方类型并开启新局。当前版本没有跨启动存档，也没有公式求解。
- 横竖屏保持同一状态；按钮自动移到底部或右侧，浏览器与 iOS 均避开安全区。

`model.ts` 使用整数格点和有符号正交基；规则不依赖 GPU、DOM 或浮点累计旋转。镜面各轴采用不同宽度，块围绕偏心核心旋转，打乱时产生真正的异形。`session.ts` 按动画完成时提交状态/历史，回放反向取出历史，不递归生成新历史。

```sh
npm run typecheck
node --experimental-strip-types --test games/test/rubiks-cube.test.mjs
npm run build:target -- game:rubiks-cube
node scripts/verify-rubiks-cube.mjs
```

最后一项复用 Engine Chrome/WebGPU 验证器，在 390×844、844×390 下对所有魔方执行打乱、GUI 转层、透视视角下的表面拖动、撤销、回放和 GPU 错误检查，并检查圆角几何缓存数量有界，保存截图及构建哈希到 `.artifacts/rubiks-cube/`。截图须人工目视核验。浏览器入口为 `games/rubiks-cube/index.html`。

原生 App 见 `Native/examples/rubiks-cube/README.md`（工作区相对路径）。
