# 数独生成性能验证

2026-09-20，同一台 Mac，独立 Node 进程运行优化前后版本，各按相同顺序生成 18 题（六种配置 × seed 39、20260920、20260921）。测试时本次全仓测试已结束；运行时间不作为自动测试的通过阈值。

| 配置 | 优化前平均 | 优化后平均 | 提速 |
| --- | ---: | ---: | ---: |
| 标准 LED | 124 ms | 26 ms | 4.8× |
| LED 挑战 | 648 ms | 76 ms | 8.6× |
| 常规挑战 | 1829 ms | 282 ms | 6.5× |
| 温度计＋摩天大楼＋XV＋四数和挑战 | 3035 ms | 2120 ms | 1.4× |
| 杀手挑战 | 320 ms | 149 ms | 2.1× |
| 多规则挑战（缺一门等） | 1123 ms | 565 ms | 2.0× |

计时只包含 `generate`，唯一解及挑战门槛检查在计时之外。每个进程初始缓存为空，后续样本复用摩天大楼表；这不是每题独立冷启动基准，也不是全部种子的最坏耗时。

全部 18 题的生成结果 SHA-256、唯一解证明节点数与优化前完全一致；全部通过唯一解和挑战门槛检查。种子、选格/候选顺序、搜索预算不变。数据及 Node/平台信息见 [优化前](./generation-before.json)、[优化后](./generation-after.json)。复现脚本为 `../benchmark.mjs`，可传入其他版本的 rules.ts 路径。

验证：138 项数独专项检查及 Native 6 项测试通过；Games / Native 类型检查、网页主包与 Worker 构建通过。全仓测试未全部通过：HYMUGEN 字节快照和 MUGEN viewer 断言失败；Petra 本地兼容性进程多项超时后仍继续运行，已终止该子进程。本轮数独改动未涉及这些模块，未修改它们。

iPhone 15 Plus / iOS 18.7.3 已安装优化版，25 项诊断检查通过。新局请求到 UI 更新的单次耗时：LED 挑战 seed 39 为 337 ms、常规挑战 seed 39 为 340 ms、四种高级规则挑战 seed 20260921 为 2768 ms。该数据包含 UI/Worker 开销，与上面的 Node 纯生成基准口径不同。真机日志保存在 Native 示例的 `evidence/ios/generation/`。
