# 分步提示回归

2026-09-20。`screenshot.json` 根据用户提供的完整棋盘录入，保留原有数字与绿色手动填写数字的区别。原图的 R2C2 通过基础规则得到候选 6、9。

提示先识别确实成立的单候选或完整单元唯一位置，再生成结构化的步骤。每步包含说明、观察格、证据格、被排除的候选和目标格当前候选。解释模块只使用公开规则谓词和当前棋盘，不读取答案或调用回溯搜索；生成器和难度门槛未修改。

原图选择较短的等价推理，依次显示：

1. R2C2 同行、同列、同宫出现 1、2、3、4、5、7、8，因此基础候选为 6、9。
2. 第二行有九个可填格，必须出现一个 9；只检查尚未填写的格子。
3. R2C1 < R1C1，而空格最大为 9，所以 R2C1 不能是 9。
4. R2C5 < R2C4 = 8，所以 R2C5 不能是 9。
5. 第三宫的 R3C8 已为 9，因此 R2C7、R2C8、R2C9 都不能是 9。
6. 第二行只剩 R2C2 可以放 9。目标格的候选显示从 6、9 变为 9，棋盘本身不自动填数。

Native 在棋盘下方替换输入区显示讲解，提供前进、回看、关闭及最后一步返回棋盘。正文可独立滚动；棋盘的金框表示观察位置，青框表示证据，划线数字表示当前排除。旧存档立即可用，退出后保留原有棋盘与笔记。中文、英语、日语共享相同推理结构。网页使用同一解释数据和绘制逻辑。

175 项数独专项测试通过（新增 11 项），Native 6 项测试通过。新增测试覆盖：截图六步推理；实际行/宫名称；未启用的对角线不出现在步骤里；三语步骤结构一致；修改不等号后不能复用旧结论；每次候选排除可由独立调用候选接口核验；缺格不强制补全短单元；多规则组合；绘制不修改笔记或填数。见 `tests.log`。

提示范围仍为现有单候选和完整单元唯一位置；没有这些线索时明确提示需要进一步组合推理，不凭答案拼凑“解释”。对于复杂规则，步骤显示实际相关规则、格子、已知数和该规则允许的候选；目前不是覆盖所有高级数独技巧的证明系统。

iPhone 真机独立诊断存档通过 45 项检查；模拟器 XCTest 真实点击前进、回看、关闭和返回游戏通过。四张逐步截图、安装前后存档快照及触摸日志见 Native 示例 `evidence/ios/hints/`。

## 候选删减提示

`findLogicalHint` 保留直接填数的优先级，无单候选/唯一位置时寻找区块排除、显性数对/三数组、X-Wing、不等号/温度计候选上下界、整条连续升降序的支持序列。所有候选来自公开规则，不读取答案，也不把手写笔记当成完整候选集合。短行/列/宫与短斜线不能作为“必有某个数字”的推理来源。

解释流程：观察候选 → 规则推理 → 删减前后对照 → 用户点击“应用到笔记”。关闭讲解不修改笔记；确认后已有笔记只做删减，无笔记的受影响格子补入剩余候选，其余笔记保留，不填数字。可继续提示、撤销和保存。自动候选与候选键同步已确认的推理结果。

存档中的可选 `deductionSteps` 在当前盘面上重放确定性的、可验证的推理，不保存未经验证的候选断言。落笔填数/擦除后重新以当前盘面建立推理上下文；已有手写笔记保留并按原候选设置过滤。旧存档兼容。`findHint` 仍是难度分级用的基础提示接口，不因新增高级提示降低挑战难度。

`elimination.json`：seed 39 的常规挑战，基础提示停在 34 个数字；连续 3 次区块排除、2 次数对排除后，R1C9 只剩 6。回归测试逐一强制填入被排除的候选，再用独立搜索确认不存在任何完成解；另覆盖多语言、重复点击、过期提示、笔记漏记、存档、撤销和缺门短单元。

范围：当前支持上述明确的逻辑技巧；未找到下一步时如实说明，不使用答案反推删候选。不是任意数独的完整人类解法集合。

X-Wing 另以两个方向的构造棋局验证：每个方向排除 14 个候选，逐个强制填入后均无解。真机候选删减测试共 66 项，截图见 Native 的 `evidence/ios/eliminations/`。

## 缺门 + XV 截图回归（2026-09-21）

`missing-xv-stalled.json` 来自安卓实际存档 seed `3250120724`，与截图逐格一致：26/72 已填，原提示返回空。首先可从 R1C9/R2C9 的 V 标记推出：两格候选均为 {1,2,4}，和为 5 的配对只有 (1,4)/(4,1)，所以两格都排除 2。

新增：XV/相邻连续的候选配对传播（包含“没有标记”的负约束）、显性四数组、完整九格单元的隐性数对/三数组、XY-Wing、XYZ-Wing，以及有长度/工作量上限的候选推理链。推理链使用格内互斥、同区域不重复、双候选、完整单元双位置和 XV/白点配对蕴含。缺门短单元只能建立互斥关系，不能擅自建立“必须包含数字”的强关系；不使用唯一矩形等依赖普通数独结构/唯一性的排除。

推理链采用广度优先搜索，最多 12 个关系、150 万次边访问，优先较短解释。每条关系保留依据，UI 逐页展示“假设 → 每次推导 → 矛盾 → 排除”。假设期间不修改盘面，不把条件性推断误记为候选删除。`missing-xv-chain.json` 是同盘后续推理链的回归位置。

自动回放从 26/72 到 72/72，推出剩余 46 个数字。每个不同的候选排除均独立强制该候选后执行求解，确认不存在任何完成解；没有使用存储答案产生提示。额外覆盖正/负标记、断开的缺格、XY/XYZ 共同影响范围、隐性数组的九格要求和短单元强关系保护。

技巧定义参考 Andrew Stuart 的 [Y-Wing](https://www.sudokuwiki.org/Y_Wing_Strategy)、[XYZ-Wing](https://www.sudokuwiki.org/XYZ_Wing)、[Alternating Inference Chains](https://www.sudokuwiki.org/Alternating_Inference_Chains)。本实现的推理图还加入了游戏的 XV/相邻连续约束，不是无限制回溯求解器；仍不保证任意棋局都能找到下一步。

验证结果：193 项数独测试、8 项 Native 模型测试、安卓 X4000 上 78 项 smoke 检查通过。真机本次测量打开 XV 提示 63 ms、打开候选推理链 57 ms（含界面渲染调用，并非性能上限保证）。测试使用独立存档，保留用户原棋局。

## 手动划去后的提示进度（2026-09-21）

解释按“格子 + 候选数字”识别已记录结果。每一步先从规则候选重新证明，再跳过已经全部划去的结果；部分记录时只展示仍待排除的候选，并把焦点移到尚未处理的格子。同一格的新排除以“进一步排除”区分。手动删除线只决定展示进度，不作为逻辑前提，不读取保存答案。

连续跳过后可以得到新的填数结论或候选排除；应用到笔记保存完整证明步数。查看解释不修改存档或求解候选缓存，撤销、恢复候选、重新加载后按当前状态重新判断。回归覆盖五步手动推理、XV 两格部分记录、跳步后的应用与撤销、错误删除线隔离，以及三语新增排除文案。202 项数独专项测试、10 项 Native 模型测试通过。

讲解步骤携带该步已验证候选，依据格与目标格同步展示。尤其是手动划去 XV 的 2 后，下一步的数对依据格显示 {1,4}，不会再次显示旧候选 2；绘制回归已覆盖。
