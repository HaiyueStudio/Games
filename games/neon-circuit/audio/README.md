# 极速新星 MIDI 音效

十四段原创 MIDI Format 0 乐谱及对应单声道 44.1 kHz / 16-bit PCM WAV 随游戏打包：按钮、赛道切换、撞栏、加速带、两个引擎转速层、盖章、过圈、刹车、3 / 2 / 1 / GO 提示及 30 秒背景音乐。生成命令：

```sh
node --experimental-strip-types scripts/generate-neon-audio.mjs
```

生成器先保存 MIDI，再用现有 MIDI 解析器读取音符、力度和时长，离线进行 FM 合成；撞栏混入固定种子的噪声，不使用外部采样或 SoundFont。源 MIDI、WAV、生成方式与波形指纹位于 `assets/audio/`。引擎波形采用整周期缓冲区，两个转速层随速度交叉渐变，松油门后约一秒淡出。所有播放数据只影响呈现，不改变比赛规则。

`NeonAudio` 管理限频、短期等待解锁的 UI 提示和两个引擎循环。按钮和赛道选择在菜单中可发声；发动机仅在比赛中踩油门后启动。暂停、回首页、重开、后台、系统音频中断及销毁停止驾驶声音；原生宿主在切赛道时复用一个固定 12 节点 PCM 播放池。

浏览器通过 Engine 的公开实验接口 `@haiyue/engine/experimental/audio` 播放，沿用用户手势解锁规则。两个专属总线承载低/高引擎层，第三总线承载短音效。原生端使用 `NativePcmAudioBank` / AVAudioEngine，遵循 iPhone 静音模式，预解码 WAV，不在音频线程执行 JavaScript 回调。

验证包括实际 MIDI/PCM 边界、能量及峰值检查，循环数量、交叉渐变、松油门淡出、碰撞限频和中断清理测试。浏览器与真机检查还覆盖实际资源解码、GUI/轮播、碰撞、加速带和引擎播放调度。音色喜好和设备音量平衡仍应以实际听感为准。

背景音乐是原创 E 小调电子配器，128 BPM、4/4 拍、16 小节，长度恰好 30 秒。鼓组、切分贝斯、铺底和琶音随段落变化，延迟尾音回卷到下一轮。`neon-music-score.mjs` 保存编曲与离线合成逻辑；PCM 接缝、全段能量和实际超过 30 秒的浏览器播放都有检查。音乐仅在比赛中循环，暂停、结算、返回首页或后台立即停止，恢复比赛时从曲首重新播放，不叠加音乐声部。

盖章音在 GUI 图章年龄跨越 0.5 秒的落下时刻触发一次；普通完赛不触发。过圈音由实际 lap 事件触发。倒计时与可见 3 / 2 / 1 / GO 同步，暂停恢复不重播当前数字，重开允许重新播放 3。刹车音只在有车速时按下触发一次。
