# 极速新星 / Velocity Nova

原生 iPhone 版本位于 `Native/examples/neon-circuit/`，共享本目录的赛道、规则、GUI 与特效。`NeonRaster.ts` 注入宿主的字体/图片处理；原生使用预解码本地像素及 Metal，网页继续使用浏览器资源加载。App 首页支持选择陀螺仪或虚拟摇杆，右下角为独立刹车和油门。

首页提供云端港湾、霓虹都市、反应堆回廊、彩虹之路和晴空回旋、熔火末途及莫比乌斯星环七个闭合赛道（按入门、进阶、专家、终极、极限排列）。路线图直接由各赛道采样点生成离屏位图，前四条使用 936 点，晴空回旋使用 1780 点及包含高度的投影，并交给 GuiImage 绘制，起点与实际发车位置一致。每条赛道分别保存最佳三圈成绩；新驾驶规则使用 v4 存档命名空间，保留旧版存档但不混用成绩。

首页拖动使用松手前约 100 ms 的移动速度预测惯性距离。快速甩动能连续越过多张赛道，保留实际循环方向；横向拖动超过 8 CSS 像素即视为滑动，跟手与松手使用同一门槛，轻拖也至少切换一张；点击抖动和纵向移动不触发切换。侧面卡片点击和键盘仍可逐张定位。

## 人机竞速

首页上下排列“单人计时”和“人机竞速”两个入口，点击直接开始所选赛道；人机入口右侧的难度副按钮按简单 → 普通 → 困难循环切换，只改变难度，不开始比赛。支持单人计时及一对一人机竞速，支持所有七条赛道和两种视角。模式及难度记住上次选择。双方同时倒计时发车，先完成三圈获胜；撞护栏、擦碰和火球保留减速、打断加速及反馈，但不扣耐久。仪表盘显示名次，小地图用品红色圆环及圆心标记对手；两车接近或投影重叠时，外圈扩大以保持玩家箭头和对手标记同时可见。比赛暂停会冻结双方，重新比赛重置全部进度，人机赛不写入计时挑战纪录。

`RaceOpponent.ts` 在道路的三维局部坐标系内预览曲率，只输出油门、刹车和方向三个控制量，与玩家共用 120 Hz 的 `stepRace`。三档使用相同的发动机和加速上限；不直接修改距离或速度，也不按玩家位置作弊追赶。按弯道距离、当前速度、反应时间和加速状态计算刹车点，出弯恢复油门，加速结束保留惯性。所有难度都会选择可达的中间及左右加速带，锁定目标直至驶过末端；同时检查加速带之后的急弯，避免贪加速而无法转向。横向漂移与车头误差共同修正方向，方向盘和踏板输入连续变化。简单档预判短、反应较慢、弯道漏转较多；普通档减少失误；困难档预判更远、变道更精准、持续修正方向。各档均根据可见火球的预计落地时机选择避让路线。火球在双方前方交替生成，各自独立计算一次撞击。

每次比赛使用固定种子以便复现；没有橡皮筋追赶或与玩家距离挂钩的速度加成。起步并排，车辆之间可超车穿行，护栏与落石为障碍物。同一模拟步内双方冲线时，按各自穿过终点所需的时间比例判断先后，精确相同则显示并列。

## 驾驶与损伤

- 场景按 10 单位 = 1 米换算（赛车长约 4.4 米），赛道里程与仪表共用同一尺度。仪表直接读取模拟速度并换算 km/h：常规极速 360，加速带极速 522。
- 赛车保留 GLB 导入的 PBR 贴图与颜色，使用环境漫反射/镜面光、较中性的主光，以及车漆清漆层；风挡保持独立的非金属光滑材质。
- W / ↑ 加速，S / ↓ 刹车，A / ← 左转，D / → 右转。手机提供触控按钮。
- P / 空格 / Esc 暂停，R 重开；暂停面板中的“返回首页”回到赛道选择。更换赛道后开始比赛会导航到该赛道页面，释放上一场景。
- 赛车保留独立航向。赛道切线变化会造成偏航，需要玩家主动转向；规则以 120 Hz 积分，与渲染帧率解耦。
- 护栏边界预留车身宽度。撞击伤害随速度平方和法向撞击比例增加，擦碰与正面撞击的损伤不同。碰撞打断加速、明显减速、反弹，并驱动衰减的镜头震动。
- 耐久为 100；50 以下（含 50）持续轻微冒烟，低于 30 后出现少量车身火焰并增加烟量。独立 WGSL 火焰只覆盖两处受损引擎，不包住整个车身。归零后损毁，重开恢复耐久并清空烟雾和碰撞反馈。
- 尾焰前缘固定在模型后部喷口，随车身俯仰与侧倾旋转；待机、倒计时或松开加速键迅速缩短至 1.35 世界单位。按住加速时随速度平滑延长。
- 撞栏时在撞击点喷射火星与烟尘；世界坐标粒子不会跟随赛车平移。72 个烟雾面片和 160 个火星面片循环复用，与车身共用场景深度，支持遮挡与暂停。
- 加速带使用生成的青色箭头贴图，WGSL 纹理沿赛道正向循环滚动；暂停冻结动画。镜头 FOV 使用连续曲线：静止 60°、360 km/h 时 40°、522 km/h 时 30°，并保留时间平滑过渡及现有跟车距离。
- 建筑采用固定种子生成，包含远景高楼、赛道两侧的楼群、灯带、天线、高架支柱与门架。楼群生成会避让整条赛道，包括邻近的回头弯；箱体共享几何，材质按颜色缓存。

驾驶反馈参考 [HexGL 的 ShipControls](https://github.com/BKcore/HexGL/blob/master/bkcore/hexgl/ShipControls.js) 的独立航向、碰撞排斥、减速与护盾损伤思路。此处使用适配现有引擎的赛道坐标规则、程序化场景和 WGSL 实现，没有引入 HexGL 的代码或模型资源。

## 国际化与设置

`NeonLocale.ts` 集中管理简体中文、英语和日语；默认中文，使用独立的 `neon.language` 偏好键。首页右上齿轮打开纯引擎 GUI 设置面板，语言即时应用到文本、赛道卡片和标题；卡片复用纹理层重绘，不重建比赛。手机 App 的虚拟摇杆 / 陀螺仪选择也位于该面板，网页端显示键盘 / 触控说明。打开面板会拦截轮播输入；Tab / Enter 可操作设置，Esc 关闭。旧赛道 ID 和成绩存档保留。

齿轮与面板是生成的 PNG，完整提示词见 `assets/settings-generation.json`。

## 验证

在 Games 目录运行：

```sh
npm run typecheck
node --experimental-strip-types --test games/test/neon-circuit-*.test.mjs
npm run build:target -- game:neon-circuit
node scripts/verify-neon-circuit.mjs
```

浏览器验证需要本地 Chrome 和 WebGPU。43 个场景覆盖桌面、手机与横屏首页、轮播切换中间帧、手机和平板 HUD、大字倒计时、橙色血量环、桌面/手机/横屏暂停面板、损毁/完赛、四赛道、待机、加速、滑行、半血冒烟、残血起火、碰撞与加速带，每个场景检查 69 项 GUI / 驾驶行为，手机另检查 3 项多指操作，太空关额外读取 GPU 纹理像素验证彩虹颜色随时间变化，同时采集 GPU 错误和实际赛车、烟雾、箭头资源的 HTTP 哈希。轮播回归会模拟捕获释放先于 GUI 松手回调的顺序，并等待动画结束，验证滑动选项保持、侧面卡片点击居中以及中断手势回位。截图与带来源信息的诊断结果输出到 `.artifacts/neon-circuit-compass-v2/`，不覆盖正式截图基线。

规则测试另外验证无转向必然撞墙、正确转向和刹车可无损完成四条赛道、撞击角度与速度决定伤害，以及 20 / 60 / 120 Hz 调用结果一致。

## 效果素材

`assets/smoke-puff.png` 和 `assets/boost-chevron.png` 使用内置 ImageGen 生成，分别作为透明烟雾粒子和循环加速带纹理。原始提示词与来源记录在 `assets/effects-generation.json`。运行时上传 512 × 512 版本并复用 GPU 纹理；离开页面时释放纹理和着色器资源。火星采用运行时绘制的细长发光笔画。

## 引擎 GUI

`NeonCircuitGui.ts` 使用公开的 `@haiyue/engine/gui` 组件，首页、赛道卡片、HUD、环形血量仪表、倒计时、暂停、比赛结果和触屏按钮全部进入 GuiSystem 的 WebGPU 渲染通道。HTML 只保留承载画面的 canvas 和不可见的自动化诊断节点，不再创建 DOM 控件或 SVG。缩略图由真实路线生成一次并缓存；中文及动态文案所需字形集中声明在字体图集中。

首页支持左右滑动、A / D / 方向键选择、Enter 开始，也支持 Tab / Shift+Tab 与 Enter 操作 GUI 按钮。比赛中保留原有驾驶快捷键，手机可同时按住加速和转向；按指针编号维护按键，松开一指不影响另一指。暂停、返回首页、重开、切换到后台或丢失捕获都会释放对应输入。浏览器验证通过实际 GUI 布局命中控件并调用引擎事件接口，同时检查页面不存在可见 DOM 控件。

## 驾驶与 HUD 细节

- 加速带效果结束后，超出普通上限的速度以每秒 200 世界单位衰减，满速过渡约 2.25 秒；刹车和松开加速会加快减速。仪表盘直接显示物理速度。
- 左右转向产生轻微阻力，并将当前目标极速降低最多 4%；减速和松开方向后的提速都有连续过渡。
- 倒计时使用预先缓存的粗体发光数字，透明背景；正常比赛 HUD 顶部居中显示赛道名，操作提示只出现在首页。
- 血量合并到速度表外圈，弧长随剩余血量变化；低于 2/3 变橙黄，低于 1/3 变红。左下方加速计时和横向血条已移除。
- `assets/gui-button.png` 与 `assets/gui-panel.png` 由内置 ImageGen 生成，提示词记录在 `assets/gui-generation.json`；接入 GuiImage 作为皮肤，保留引擎按钮命中、焦点和输入处理。

## 仪表与暂停面板

手机仪表盘在原位置左移 25、下移 5 个逻辑像素（超出屏幕时限制在可见边缘），保留原缩小 20% 的大小。计时和最佳成绩使用左侧两行区域，与仪表共用“大圆盘＋上部右伸、右下圆角”的科幻外框；圈数显示在指南针底部；速度、单位与 HULL 的位置及血量着色器保留。赛道名称仍用高 30 的窄幅吸顶底板。右侧使用指南针 / 暂停一体外框，暂停位于右上角，热区至少 44 × 44。窄屏自动收紧两组大小，保持中间视野和触摸范围。

`HudMapTexture.ts` 将真实赛道的水平投影缓存为路线纹理，只在 GPU 上旋转并叠加实时赛车标记。路线按圆形包围范围等比缩放，五条赛道在任意朝向都完整可见；白点表示起终点、亮色三角表示赛车，车头向上，方位字母随地图转动。过山车竖直路段保留最后有效的水平朝向，正常路段使用实际车头投影。暂停、结算与首页隐藏小地图，切赛道和销毁时释放旧纹理。地图横向以引擎追尾相机的屏幕右方为准，朝 +Z 驾驶时对应 -X；CPU 标记与 GPU 逆采样使用相同映射，倒置路段随相机左右方向翻转。回归测试同时对照真实左右弯道和相机矩阵，避免只测车头朝上漏掉镜像。当前素材原图及内置 image_gen 的完整提示词见 [hud-v2-generation.json](./assets/hud-v2-generation.json)。

比赛中仅有右上角圆形双竖线暂停入口，保留 44×44 触控区域。符号由 GUI 文字层绘制在图片皮肤上方。暂停面板提供“继续游戏”和“返回首页”，暂停时冻结倒计时、物理和特效，清空驾驶按键，隐藏底层比赛信息；全屏输入拦截层完全透明，不再绘制外围纯色蒙层。暂停、损毁和完赛面板的图片不透明度约为 72%，文字保持清晰。Tab / Shift+Tab 仅在面板按钮间切换，Enter 执行；P / 空格 / Esc 也可以继续。损毁或完赛后显示结果面板，提供“再次挑战”和“返回首页”。

刷新个人最佳成绩时，标题高亮为“新纪录！”，右上角的金色图章从放大、倾斜状态落下，伴随轻微回弹和面板震动，每次结算只播放一次。普通完赛和撞毁不显示图章。HULL 在此前调整基础上再上移 4 像素。移动端浮动摇杆显示为科幻方向盘，左右滑动时围绕初始触点旋转，松开后淡回半透明待机状态；油门和刹车各自按真实按压状态向后倾斜、下沉并回弹，动画不会移动触控区域。

图章和方向盘由内置 ImageGen 生成，原始素材与完整提示词见 `assets/interactive-hud-generation.json`。`HudSpriteTexture.ts` 在 GPU 上投影这些 GUI 图片及踏板皮肤，静止时复用结果，退出时释放纹理和缓冲区。

最新 `assets/gui-title.png`、`assets/gui-timing.png`、`assets/gui-pause.png` 使用内置 ImageGen 生成，完整提示词与来源保存在 `assets/top-hud-generation.json`；原始 RGBA 不改写，通过 GuiImage UV 选取有效区域。圆盘素材的原始提示词仍在 `assets/hud-generation.json`。底图通过 GuiImage 显示，速度、血量和赛道文案保持实时渲染；统一在退出时释放 GPU 资源。

## 赛道轮播

横屏首页将赛道轮播放在左侧、模式按钮放在右侧，卡片宽高较原布局放大 50%；竖屏按屏幕宽度适配以保留完整卡片。左右切换使用代码绘制的半透明发光箭头，悬停或按下时提亮，复用两张纹理。首页以 3D 透视轮播展示赛道：中央卡片正面放大，两侧卡片旋转后退，并随拖动或按键平滑过渡。可点击侧面卡片、左右箭头，或使用 A / D / 方向键循环选择；手势仅接受有明确横向位移的滑动，轻触、竖向移动与取消不会误切换。拖动后抑制同一次点击，失去指针捕获、窗口焦点或离开首页会取消手势。

`CircuitCarousel.ts` 将真实路线和静态文案缓存为四层纹理，使用已有面板素材进行透视合成，最终仍由引擎 GuiImage 显示。GPU 合成与 GUI 命中检测共享 `CarouselMath.ts` 的投影参数；静止时复用结果，切换尺寸时替换纹理，退出时释放全部资源。使用图片皮肤的按钮和卡片将原生背景、边框设为透明，悬停和键盘焦点通过图片明暗表示。

定向复查可传入场景名，例如 `node scripts/verify-neon-circuit.mjs idle high-speed high-speed-mobile`。不传参数时仍执行完整矩阵，未知场景名直接报错。


## 配色与彩虹之路

`CircuitThemes.ts` 为空港（暖金 / 青绿）、都市（青蓝 / 品红）、反应堆（紫色 / 黄绿）与星海提供独立的路面、护栏、建筑、灯光及背景配色。成绩按赛道 ID 保存，调整显示顺序不会影响对应关系；不同赛道尺度的成绩按规则版本分开保存。

第四关使用悬浮的立体 8 字路线，上下交叉点相距约 3060 世界单位；坡道、倾斜弯道、路线缩略图、碰撞和赛车姿态由同一条采样路线驱动。`RainbowRoadTexture.ts` 在 GPU 上生成饱和彩虹瓷砖，颜色与柔和光带持续流动，纵向 UV 整圈无缝衔接。彩虹顶面替换基础道路顶面，避免重复共面；每帧在 GPU 上生成 mip 链并使用各向异性过滤，减少远景网格闪烁。

`SpaceEnvironment.ts` 加载生成的宇宙全景、三颗不同的带环行星和流星贴图。全景球跟随相机，行星保留世界坐标视差；36 个流星实例按固定相位循环，使用场景深度遮挡。太空关移除城市地面、建筑和落地支柱，突出悬空的赛道。暂停冻结动画，离开页面释放纹理。原始提示词和内置 ImageGen 来源记录在 `assets/space-generation.json`；计时面板素材记录在 `assets/timing-generation.json`。

引擎、相机及 Render3DSystem 一致启用 Reverse-Z，使用 `depth32float`，改善远处路面和标线的深度精度。`RoadOverlay.ts` 将标线、横带和加速带裁剪到路面的实际三角面上，避免倾斜弯道中独立挤出的覆盖层穿进道路；起点处保持贴面和连续 UV。高速时 FOV 平滑收窄，同时抬高视线约 12.6°、增加前视距离并跟随坡度，保持赛车完整可见并展示更远的道路。浏览器验证记录反向深度状态、深度格式、镜头角度、太空实例数，并检查计时面板在暂停按钮左侧。


## 高速赛道比例

四条路线统一放大至原来的 1.8 倍，路宽、赛车和模型尺度不变。弯道半径随之增加，单位距离的航向变化约减少 44%；采样点同步增加到 936，保持道路网格密度。城市地面、远景边界及太空景物同步扩展。

常规极速提高到 1000 世界单位/秒（360 km/h），加速带极速为 1450（522 km/h）；加速、刹车、加速带推力和超速回落同步调整，高速转向角速度略收敛。镜头与尾焰按新的极速归一化，仪表仍读取真实物理速度。新版成绩使用 v4 保存，旧赛道的成绩保留在旧存档中，避免把不同赛道长度的圈速混在一起。

## 晴空回旋与 F1 方向盘

第五关 `sky-coaster` 使用晴天云海全景、蓝灰路面、青色护栏和橙色点缀；路线长约 8.2 km。独立参数曲线包含错开进出口的垂直回环、完整 360° 翻转、一圈半爬升螺旋及切线衔接的返回路段。路面方向沿中心线连续传递，并修正闭合接缝；赛车姿态、悬浮偏移、护栏和相机共同使用这组方向，不在竖直位置切换世界朝向。转向根据路面平面内的曲率计算，垂直回环不会被误判为 180° 转弯；玩家仍需主动转向通过平面弯道。倒置路段的标线与加速带沿实际三角面法线抬升，保持在可驾驶的一面。

方向盘换成开顶、平底、双侧握把的 F1 风格科幻造型，保留浮动中心与转向旋转，未按下时以 36% 不透明度展示，按住时平滑变清晰。内置 ImageGen 生成原始 `assets/gui-wheel.png` 和 `assets/sunny-panorama.png`，完整提示词见 `assets/coaster-generation.json`；原始 PNG 保留，原生打包保持全景比例。

定向浏览器验收：`node scripts/verify-neon-circuit.mjs coaster-overlook coaster-loop coaster-roll coaster-helix home-coaster`。确定性测试覆盖连续正交方向、闭合接缝、倒置横向偏移、双向转向、倒置贴花，以及五条赛道三圈无损完赛。

每圈完成的 `LAP n / 3` 提示采用生成的横向科幻通知底板 `assets/gui-lap.png`，原纯色背景透明化；GUI 继续绘制实时文字。内置 ImageGen 原始提示词和 UV 使用记录见 `assets/lap-generation.json`。待机方向盘仅在虚拟摇杆驾驶模式显示，暂停、结算、首页及陀螺仪模式隐藏。

### 熔火末途与第一人称（2026-09-14）

第六条赛道 `ashfall` 使用黑色玄武岩、橙红护栏、火山末日全景和三个带动态喷发碎块、灰烟的火山。路面火球使用固定步长、赛道种子和最多四个复用槽：提前 1.65–2 秒显示固定落点，撞击区仅覆盖部分路宽，爆炸持续 0.9 秒。命中造成 16–36 点伤害、降速和震动/声音反馈；跨圈和高速经过落点使用连续碰撞检测。暂停冻结火球，重开清空并重置随机序列。

设置增加第三人称/第一人称（中英日），独立保存为 `neon.camera`；开始比赛时应用视角变更。第一人称不创建赛车 glTF 组件和尾焰，原生模型几何读取改成按需加载；相机沿路面方向放在赛车位置上方 13 单位，兼容倒置回环。耐久损失时叠加四档累积玻璃裂纹（99–67、66–34、33–16、15–0），只在第一人称显示，重开恢复透明。裂纹纹理仅在第一人称场景创建并缓存，HUD 和按钮位于裂纹之上。

手机隐形摇杆保留按下位置作为控制中心，最大半径从 46 增至 57.5 点。F1 方向盘图像固定在安全区域左下角，随转向旋转，触点移动不会改变图像位置；未按下保留 36% 不透明度。

全景由内置 ImageGen 生成：[volcano-panorama.png](./assets/volcano-panorama.png)，提示词记录：[apocalypse-generation.json](./assets/apocalypse-generation.json)。另有 [volcanic-rock.png](./assets/volcanic-rock.png) 用于火山与落火球表面；原生打包保留全景原始宽高比例。

### 莫比乌斯星环与三车道短加速带

第七条赛道 `mobius-ring` 使用同一条半扭转带的定向双覆盖：沿星环绕一周到达背面，再绕一周回到起点，完成一圈比赛。两面相隔 12 个世界单位，连续道路坐标系同时驱动车辆、路面网格、碰撞与相机，支持第三人称和第一人称。复用宇宙全景、光环行星和流星资源；路面通过 WGSL 多层 noise 生成流动星云与等高线花纹，沿赛道方向无缝循环，并逐帧生成 mip 层以稳定远景采样。

所有赛道使用 `BOOST_PADS` 统一生成可见几何与触发范围：每条赛道 15 块、每块长 96、宽 32，左右偏移 ±58，中间与左右各 5 块，沿前进方向错位分布。加速到期仍保留原有平滑减速。

针对性验证：`node --experimental-strip-types --test games/test/neon-circuit-*.test.mjs`；浏览器场景新增 `mobius-overlook`、`mobius-front`、`mobius-back`，覆盖 GPU 纹理变化、正反面相机及真实太空资源哈希。验证输出写入 `.artifacts/neon-circuit-mobius/`。

### 三维赛道小地图

小地图保留全部采样点的 XYZ 坐标，以固定包围球缩放。采用赛车完整道路坐标系的逆旋转与固定斜俯视投影，统一处理偏航、俯仰、翻滚，不再使用水平朝向加正反面符号切换。赛道线段在 GPU 上生成固定像素宽度的曲线，并用深度测试和远近明暗显示立体交叠；赛车标记采用同一投影。线段缓冲只上传一次，每帧只更新朝向和标记，不再生成或回读 Canvas 图片。

### 按撞击方向生成玻璃裂纹与第二关缓弯

碰撞规则记录驾驶视角下的 `damageSide`，玻璃裂纹按实际受损侧累积。每次受损使用不同的种子与落点，分支形状、长度也有变化；碎裂程度随伤害加深，中央视野留空。持续擦墙的小额伤害合并绘制，最多保留 10 组裂纹，重开清空并产生新的布局。只在裂纹变化时更新同一张 GPU 纹理，避免按帧创建纹理。

第二关霓虹都市调整中段内凹折弯与终点前的回折，保持路宽和控制点高度。两段原峰值曲率约 .00344 / .00532，调整后约 .00159 / .00144。赛道缩略图、小地图、路面与碰撞共用更新后的路线。该关的最佳纪录采用 v5 命名空间，与旧路线成绩分开；其他赛道保持原纪录。

### 2026-09-24 每帧渲染工作量

动态纹理的 `update/render` 可接收当帧 encoder 获取函数，由游戏在外观、GUI 动画和 HUD 更新结束后统一提交，再绘制场景；初始化和独立使用仍可立即提交。各纹理必须拥有独立 uniform，同一批次内不可用不同参数重复更新同一个生产者。`snapshot().dynamicTextures` 记录当帧生产者编码次数与统一提交次数。

时间、最佳时间、速度、耐久/名次与圈数使用独立 `GuiRoot`，复用引擎按根缓存，避免时间更新使静态 HUD 重建。读数根禁用输入命中并沿用原布局锚点，静态布局变化时同步失效；`guiView.snapshot.cacheWork` 可检查静态与读数布局次数。暂停、结算和首页会隐藏读数。
