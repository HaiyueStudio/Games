# 阡陌交通

点击画卷上方的“选卷”，或按 `Esc` / 手柄 `L3`（按下左摇杆），当前画卷会先收拢，再展开棋盘选择页。中央展示大幅山河预览，两侧是相邻棋盘的淡墨缩略图；左右轮播山河、环山、三岔、六瓣，棋盘以 noise 遮罩与渐隐渐显交替出现。下方单独轮播独行、共盘对弈、双盘竞分、续流四种模式；双盘显示两幅棋盘，续流只展示独立无界地图。

选卷时，键盘左右 / 手柄 X、Y、LB、RB 切换棋盘，上下方向键或 `M` / `Start` 切换模式，回车 / `A` 或“展卷入局”确认并重新开局。鼠标可点击轮播箭头，触摸可在棋盘区域横向滑动换卷，在模式区域横向滑动或上下滑动换模式。`B` / `Esc` 或“返回此局”收卷返回，保留当前落子、旋转、分数和机器待落子回合。只有确认后才应用选择；预览使用独立的地形 worker 与有上限的图片缓存，不改写当前盘面和存档。

画卷上方可选择四种模式：

- **独行**：原有的路径拼图，保留原来的独立存档和最高分。
- **共盘对弈**：玩家先手，与机器交替放置同一棋盘上的棋子。谁落子后令水路撞墙、走出棋盘或形成封闭循环，谁输。
- **双盘竞分**：两盘使用相同地图种子、出水口和抽牌序列。玩家落一手，机器再落一手。一盘先结束时，另一盘继续，直到双方结束；总分高者获胜，同分平局。
- **续流**：使用一张独立、没有山脊边界的开放地图，地图随水路自动展开，镜头平滑调整以保持棋子可见，未探索区域以淡雾融入画卷。初始 6 格生命，中央是一块完整的六路径棋子，第二圈六个方向各预置一块花木特殊棋子。每次落笔消耗 1 格生命；水流每经过中心的一条新路径恢复 1 格生命，每经过花木特殊块的一条新路径恢复 **2 格生命**。相同路径不重复奖励，初始出发路径也不奖励。先扣除再计算奖励，因此最后一格生命可以在本手补回；奖励可累积超过 6 格。生命归零或形成闭环时结算，沿用新增河段的三角计分，单独记录续流最佳成绩。

上方棋盘选择器供独行、共盘对弈和双盘竞分使用，提供山河、环山、三岔和六瓣四种棋盘。三岔、六瓣采用参考图中的平顶六边形，保留中央泉眼和封闭山脊；第一张参考图裁掉的上缘按左右对称补齐。续流使用固定的独立布局，隐藏棋盘选择器，`[` / `]` 不切换续流地图；退出后仍可选择原有棋盘。曲径已移除，旧存档和最高分按地图标识迁移，避免序号变化串档。

机器枚举当前牌、备用牌的全部六种旋转，优先选择本手不会结束的方案，再最大化本手新增河段的三角分数。并列时优先当前牌、较小旋转角度。算法只评价当前落子，不搜索后续牌或对手回合。

对战和续流种子为 `0–4294967295` 的整数。输入后点“同种重赛”应用；“新一局”会换种子。切换地图或模式沿用种子。自动保存当前模式的落子记录及尚未提交的选牌/旋转，刷新后恢复；续流同时恢复生命与已奖励路径，机器待落子回合也会继续。

续流开放地图使用版本 2 的落子记录。之前套用有限棋盘的续流存档会重新开局，原有最佳记录仍保留；开放地图使用独立成绩标识。地形按世界坐标确定共享接缝，只在专用 worker 中增量绘制新区域，已有水路、地形和奖励记录不会因扩图重置。

四种模式共用键盘、鼠标、触摸和手柄输入，以及河道绘制、旋转、换牌动画。将指针移到当前棋子即可显示旁边的毛笔旋转箭头，点击棋子落笔，点击侧边备用牌换牌；竖屏和手柄操作时直接显示箭头。鼠标右键和滚轮也可旋转。机器落子期间不接受玩家改动，赛后点击画面可同种重赛。当前棋子的墨晕在相邻格绘制后叠加，六侧都可见。续流以赭金区分中心、朱砂区分花木特殊块、丹青表示普通块；右上角和中心显示余命，花木周围的六瓣标记显示剩余可奖励路径；奖励时有绿色扩散与对应的 `+1` / `+2` 浮字。

共盘盘面接近单人模式大小；双盘在横屏并排、竖屏上下排列，减少标题和操作区占用的空间。

棋子使用俯视水墨山体：同一幅山势按世界坐标铺开，再裁入相邻六边形，跨格山坡和岸线共用接缝；内部根据六条路径切出河谷，并在河道围出的区域填入不同山峰、山脊组合。旋转改变内部山块分区，边缘山势保持固定，续流扩图也不会重画已出现的山。山体浓淡、纹理与河谷留白采用独立种子，普通块保持青绿墨色，中心与花木块保留赭金、朱砂区分并保留山体明暗。地形覆盖遮罩由专用 worker 计算，已生成的路径素材缓存复用。浏览器验证另输出 `artifacts/entanglement-path/desktop-mountain-materials.png`，对照同一片山势下的六种路径素材。

四种模式共用逐格得分动效：水流每经过一条本手新增的河段，在对应棋子上方依次显示水墨 `+1`、`+2`、`+3`……，重新经过旧棋子的新路径也在该棋子上显示，相同路径不重复。数字出现时机跟随水流走出该格的时间，随后上浮、晕散成墨流，沿弧线汇入对应的分数栏；栏内数字随着每笔墨迹抵达逐次滚动累加，例如三段显示 `+1 / +2 / +3`，最后累计 6 分。双盘双方各自飞向自己的分数。扩图与横竖屏变化时重新计算起点、终点；规则分数即时保存，动画不阻挡落子，结束后显示值与规则总分一致。特效有数量上限，复杂墨流限制并发但保留各格数字，重开、换图、切模式时清空，读档直接显示已保存总分，不重播旧动效。
