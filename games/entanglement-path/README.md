# 阡陌交通

画卷上方可选择三种模式：

- **独行**：原有的路径拼图，保留原来的独立存档和最高分。
- **共盘对弈**：玩家先手，与机器交替放置同一棋盘上的棋子。谁落子后令水路撞墙、走出棋盘或形成封闭循环，谁输。
- **双盘竞分**：两盘使用相同地图种子、出水口和抽牌序列。玩家落一手，机器再落一手。一盘先结束时，另一盘继续，直到双方结束；总分高者获胜，同分平局。

上方棋盘选择器在三种模式下均可使用。新增参考图中的“三岔”和“六瓣”轮廓；采用平顶六边形，保留中央泉眼，山脊封闭外缘。第一张参考图裁掉的上缘按左右对称补齐。原有山河、环山、曲径棋盘保留，存档索引不变。

机器枚举当前牌、备用牌的全部六种旋转，优先选择本手不会结束的方案，再最大化本手新增河段的三角分数。并列时优先当前牌、较小旋转角度。算法只评价当前落子，不搜索后续牌或对手回合。

对战种子为 `0–4294967295` 的整数。输入后点“同种重赛”应用；“新一局”会换种子。切换地图或模式沿用种子。对战自动保存落子记录及尚未提交的选牌/旋转，刷新后恢复；机器待落子回合也会继续。

| 操作 | 键盘 | 手柄 |
| --- | --- | --- |
| 逆时针 / 顺时针 | 左 / 右方向键 | X、LB / Y、RB |
| 换备用牌 | B | B |
| 落笔 / 赛后同种重赛 | 空格、回车 | A |
| 循环切换模式 | M | Start |
| 切换对战地图 | `[` / `]` | 画面地图控件 |

画面上的毛笔箭头、备用牌和“落笔”均可点按；也可直接点当前棋子落笔。鼠标右键和滚轮可旋转。机器落子期间不接受玩家改动。

验证：`npm test --workspace @haiyue/game-entanglement-path`、`node games/entanglement-path/verify-browser.mjs`、`node games/entanglement-path/verify-versus-browser.mjs`（从仓库根目录运行）。
