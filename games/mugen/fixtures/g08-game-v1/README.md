# G08 browser game fixture

This self-authored MIT fixture supplies the executable DEF/CMD/CNS/AIR portion of the G08 browser fight. It deliberately reuses the generated `g05-viewer-v1/hero.sff` and `hero.act` binary assets so the repository keeps one canonical copy of the geometric fighter artwork.

The two selectable fighters are deterministic palette/name variants of the same minimal character program. This fixture is not intended to claim full third-party MUGEN character compatibility.
