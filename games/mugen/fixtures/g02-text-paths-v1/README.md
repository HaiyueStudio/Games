# G02 text/path fixture

This directory is a Haiyue-authored MIT-licensed fixture for the MUGEN G02
VFS, text, dependency-graph, and package-codec contract. It is not a playable
character.

`hero.sff`, `hero.snd`, and `hero.act` are deliberately small dependency-graph
placeholders. They are not valid SFF, SND, or ACT format fixtures and must not
be used as evidence for G03 or G06.

The authoritative file hashes, license anchor, source-set hash, dependency
graph hash, and `.hymugen` golden hash are recorded in `fixture-manifest.json`.
