初めの駄文
--------------------------------------------------------------------------------
ARCANA HEART2からペトラ・ヨハンナ・ラーゲルクヴィストです
はぁとのライバルとして作られたキャラですが、思いっ切り主人公してますよね
でも、どうやら公式でははぁとに負けたらしい？ニコニコMugenwikiがソースなんでちと怪しいですが……

画像が荒いのは内部データがそうだったため仕様です
いつか綺麗な画像に変更できたらなぁと思います
ちなみに、デフォルトでは攻撃力と受けるダメージを3/4にしてます

現在、一部原作と違うところがあります
銃関連使用時のエフェクトが無い
吹っ飛ばし、打ち上げ時のエフェクトが無い
勝利演出が一部搭載されてない(ノーラの一部の画像が入っていない？ため)
各種相殺が不自然(今回はそこまで手が回らなかったので)
などです

一部パレットは道頓堀まじかさんに作ってもらいました
制作していただきありがとうございます

ちなみに、AIやカラーとか色々募集してます
もし作ってみたぜっていう方いたら連絡くださいな

ボタン配置
--------------------------------------------------------------------------------
A = 弱攻撃
B = 中攻撃
C = 強攻撃
Z = ホーミングボタン
X = アルカナボタン
Y = 現在未使用
START = 現在未使用

なお、CAPCOM配列にしたい方(ようはCAPCOMやSNKキャラと戦いたい方)は
CMDの一番上にある[Remap]の部分の;を全て外してください
ちなみに、外すと

X = 弱攻撃
Y = 中攻撃
B = 強攻撃
A = ホーミングボタン
Z = アルカナボタン
C = 現在未使用
START = 現在未使用

というボタン配置になります

なお、人によっては中攻撃を下に持って行きたい方もいるでしょうから
そういう場合はCMDの二番目にある[Remap]の部分の;を全て外してください
ちなみに、外すと

X = 弱攻撃
A = 中攻撃
B = 強攻撃
Y = ホーミングボタン
Z = アルカナボタン
C = 現在未使用
START = 現在未使用

というボタン配置になります

その他のボタン配置にしたい方は３番目を自分で弄ってください

--------------------------------------------------------------------------------
モードセレクトについて
--------------------------------------------------------------------------------
イントロ時に、キャラクターのモードセレクトが現れます
上下でモードを選択し、スタートで決定してください
スタートで決定すると、アルカナの画像とアルカナのモードセレクトが現れます
上下でモード選択、左右でアルカナの切り替え、スタートで決定してください

なお、モードは最初の対戦の時にしか変更できませんが、アルカナは対戦の事に変更できます

--------------------------------------------------------------------------------
モード説明
--------------------------------------------------------------------------------
現在、６つのモードが選択可能になっています

以下、モード説明

アルカナモード
アルカナ２の性能で各種補正など無印と同じにしたモード
以下、アルカナ２モードとの変更点
防御力(根性補正値)の増加
吹っ飛ばし、打ち上げがそれぞれ前強、斜め前強に変更
それに伴い、斜め前強、前強が使用不可能に
空中特殊攻撃が空中下強に変更

Fullモード
すごカナの性能で各種補正などFullと同じにしたモード
防御力(根性補正値)の増加
以下、すごカナモードとの変更点
吹っ飛ばし、打ち上げがそれぞれ前強、斜め前強に変更
それに伴い、斜め前強、前強が使用不可能に
空中特殊攻撃が空中下強に変更

１アレンジモード
２アレンジの性能で各種補正など１アレンジと同じにしたモード
(ただし、ホーミングボタンを押しながらエーテルを使用する必殺技を使用してもエーテルが０の時の性能にはならない)
以下、２アレンジモードとの変更点
防御力(根性補正値)の増加
吹っ飛ばし、打ち上げがそれぞれ前強、斜め前強に変更
それに伴い、斜め前強、前強が使用不可能に
空中特殊攻撃が空中下強に変更

アルカナ２モード
アルカナ２の性能と殆ど同じ

すごカナモード
すごカナの性能と殆ど同じ

２アレンジモード
様々な部分をアレンジしているモード
すごカナと主な変更点は
連続技始動時の弱攻撃の補正を強く
しゃがみ弱が４フレに(アルカナ２版と同じ)
銃を使用する通常技使用時、エーテルの保有数によって攻撃力が変動するように
地上ニュートラル投げ、空中投げがアルカナ必殺技、超必殺技、アルカナ超必殺技でキャンセル可能に
エーテルを使用する必殺技使用時にホーミングボタンを押しながら使用する事でエーテルが０の時の性能になるように
L.G.A.dodgeの無敵時間が減少したかわりに、キャンセルで出した行動にも無敵時間が切れるまで無敵が持続するように
L.G.A.dodgeが押したボタンによって付加する無敵が違うように(弱は打撃無敵、中は飛び道具無敵、強は投げ無敵)
L.G.A.dodgeがホーミングキャンセルできなくなった代わりに、超必殺技でキャンセル可能に
超必殺技ガード時に、ホーミングキャンセル不可
CF版L.G.A.combination fireの追加

因果の意の設置が本体が攻撃されても消えないように

種蒔き及び花満開が落下中及び地面に接触後、攻撃で消されないように
種蒔き及び花満開の攻撃が相手ダウン時に発動しないように
種蒔き及び花満開の出せる個数が上昇
養分吸収が相手のレバガチャによって回復量が減らないように
養分吸収のレバガチャによる回復量が減少
禁断の実と花が相手が仰け反っていてもヒットするように
他色々
