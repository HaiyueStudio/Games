# POW、图集与远景更新

POW 现在是与普通砖相同的 1×1 实体。玩家可以站在上面，侧面会阻挡玩家、怪物和龟壳。普通跳落、走路碰触和从下方顶到都不会引爆；跳起按下键完成翻筋斗后向下砸中才会引爆。Shift 抱起，松开轻放，J 投掷。小体型抱着时也保持完整大小，投出位置位于人物前方且不插入地面。

投掷中的 POW 命中第一个敌人时，先击败直接命中的敌人，再震杀屏幕内站在地面的敌人；直接命中的敌人即使在空中也会被击败。碰撞按飞行路线顺序判断，不取决于敌人数组顺序。投掷落地或撞墙也会引爆；高速龟壳撞上同样触发爆炸。冲砸中的石头怪撞上 POW 会引爆并被击败，石头有翻转下落、消散动画。镜头震动和闪光保持有界，重试恢复全部初始对象。

石头怪的闭眼、警觉、愤怒帧重新按完整连通轮廓裁切，共用正方形画布，去掉先前混进来的相邻精灵。三帧与 2×2 碰撞体对齐。

金币使用新生成的 [12 帧半周旋转素材](assets/tokens-half.png)：每帧间隔 15°，从 0° 到 165°，下一次循环对应 180°。两面均有 Token 图案，侧面来自真实绘制的窄边视角；共用画布，保持中心和高度。游戏、编辑器图标和 HUD 均使用每秒 24 帧，冰砖内的金币仍停在第 0 帧。[生成提示词](assets/polish.provenance.json)。

编辑器没有选中可配置机关时，右侧显示「远景 / 背景」：海岸云朵、珊瑚城堡、远山、原野平原。三个新远景来自 [生成全景原图](assets/distant-landscapes-clean.png)，[提示词](assets/distant-landscapes-clean.provenance.json)。选择会立即预览，试玩、保存、读取、JSON 导出导入、撤销重做和死亡重试都会保留。`Level.backdrop` 可为 `coast | castle | mountains | plains`，省略兼容旧地图。远景以镜头移动的 8% 滚动，并交替镜像拼接，使用普通 2D 渲染；选择按钮、预览图及 HUD 使用 Engine GUI。

运行时素材统一放在 `assets/runtime/`。`pack-runtime.py` 从原始 PNG 按使用帧裁切、排除废弃图块，以 48 像素地砖和实际角色尺寸为基准，通常保留两倍采样分辨率；云朵保留完整轮廓和透明边距。角色动作在同组中使用相同缩放比例。原始 PNG 留在源码目录，供后续美术修改，不进入发布清单。运行图集保留稳定帧号，废弃帧不分配 GPU 平面。包含新远景的运行 PNG 合计约 6.9 MB，比对应原图约 46.3 MB 减少约 85%；逐图大小、使用帧和移除帧见 [打包报告](assets/runtime/packing.json)。

重新生成运行图集：`python games/whale-maker/assets/pack-runtime.py`。重新测量原图时先运行 `measure-atlas.py`，再运行打包脚本。

验证：`games/test/whale-maker-pow.test.mjs`、`verify-polish-browser.mjs`。实际 WebGPU 截图输出到 `artifacts/whale-maker-polish/`，覆盖 POW 站立和下砸、石头各表情及被击败、金币正侧面，以及远景选择和试玩。
