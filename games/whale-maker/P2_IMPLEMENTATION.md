## 16：五种独立穿戴能力

穿戴装备与身体形态分开，可组合初始、长高、火、冰、巨型、猫、回旋镖和建造锤八种身体形态。碰撞宽度仍为普通／长高 0.9 格、巨型 1.9 格。装备不会拉伸身体图像。

| 装备 | 操作与行为 |
| --- | --- |
| 鲸炮箱 | 按住 J 蓄力，松开发射；短按普通炮，约 0.6 秒进入蓄力炮。蓄力炮可破普通砖，接通敌人／首领抗性及透明管道。持物时 J 优先投掷。 |
| 旋桨箱 | K 上升，默认每次离地三次，落地恢复；下键俯冲。编辑器可改次数，补充时恢复该配置值。水中和持物时不能发动。 |
| 咕嘎面具 | 安静移动时抑制识别型敌人的追踪／主动发射；跳跃、旋转、攻击、特殊动作、坐击和持物会暴露约两秒。身体接触仍按敌人规则结算。 |
| 鲸弹面具 | K 开始／提前结束一次四秒推进；左右转向，上下调整高度；撞墙或计时结束停止推进。水中和持物时不能发动。 |
| 红脉冲箱 | 从下方碰撞天花板／砖触发红 POW，默认三次，耗尽消失；次数可编辑，短冷却防止同次接触重复触发。 |

普通受伤先消耗帽子；没有帽子时再消耗穿戴装备，保留身体形态；挤压、超时与坠落按死亡处理。铁盆、龟壳帽和尖刺龟壳帽均挡一次普通伤害，不再局限于头顶方向；丢帽后有短暂无敌，长高／火／冰／巨型等状态保留。过门／管道取消当前蓄力和推进，保留装备与剩余次数；死亡清空。原铁盆的拿取、轻放、戴盆、坐盆规则保留。触屏 K、原开火按钮以及既有手柄映射可直接操作。

## 17：敌人与龟壳车

| 元素 | 行为 |
| --- | --- |
| 蜜蜂 | 有加速过程的二维追踪，遇墙回避；伪装时回到巡游锚点。 |
| 弹簧小怪 | 跳跃移动；翅膀型跳得更高。踩掉翅膀／巨大修饰后再踩，才变成一只可搬运纵向弹簧；掉落一次。 |
| 环绕幽灵 | 以放置点为中心，按数量、半径和速度等距成环。 |
| 推人企鹅 | 接触推挤，普通攻击造成击退；冰冻可后续击碎，岩浆等环境可击败。 |
| 巨型食人鱼／岩浆龙 | 等待、从液面下进入、跳出、退出、间隔重复；匹配水／岩浆升降时，发起位置随液面变化。食人鱼承受三次轻攻击；岩浆龙不受火／冰影响。未放液体时以编辑锚点为基准。 |
| 追踪／巨大／猫炮弹 | 分别追踪、沿原方向前进、较快追踪并破普通砖；巨大炮弹也可破砖。接入炮台／管道内容选择、透明管道和抗性表。 |
| 魔法龟 | 发射魔法并在合法空间传送；只把原始普通砖变成金币或小怪，不改变奖励砖、硬砖或 P 临时金币砖。每只最多变换八块。 |
| 龟壳车 | 附近按上驾驶；方向键加速、跳跃；Shift＋上离车。默认三点独立耐久，可编辑；高速撞普通怪，静止车仍阻路，损坏使用对应帧。 |

炮弹寿命十二秒，魔法／飞镖五秒，鲸炮弹 2.5 秒。鲸炮最多八枚，魔法与飞镖合计最多二十四枚；通用生成仍受敌人 256、实物 128、奖励 64 的数量上限约束。换区清理玩家发出的弹丸；敌方弹丸归各自区域。暂停不推进模拟。

## 18：首领与重物

新增三类首领各有独立动画、行为阶段、生命条与战斗示范。默认拳王／幻忍为 2×2、三点生命；龙王为 3×3、六点生命，均可编辑耐久。

| --- | --- | --- | --- | --- |
| 普通火／冰／回旋镖／鲸炮 | 非缩壳时，三次轻命中扣一点 | 真身可见时，三次轻命中扣一点 | 疲倦窗口，四次轻命中扣一点 | 延续一次有效攻击扣一点，五点生命 |

## 19：时序与环境机关

- **节拍砖**：周期与相位可编辑，同一模拟时钟控制显隐，变换前闪烁；从虚体变实物时复用实体化挤压结算。
- **坠落圈砖**：人物、敌人和实物站上后预警；预警期间离开可取消。到时带乘客下落，离场后等待复位；原位有人时延迟返回，避免把对象挤进砖中。
- **冰柱**：玩家接近下方时预警、下落，命中地面／敌人／首领／玩家后碎裂，等待重生；铁盆仍可承受头顶伤害。
- **龙卷风**：同一矩形风场持续托起人物、敌人、实物及奖励，附带向中心的轻微水平力；宽、高和风力可编辑。

机关的尺寸预览与碰撞范围一致；越界配置不能导入或批量编辑。重试从原始地图重建，未激活区域保存自己的机关阶段，返回时节拍／液面按当前关卡时钟同步。

## 20：主副区域、镜头与进度

编辑器空选区打开 **高级 / 条件**，翻页进入主副区、方向、宽高、生命、镜头及液面设置。可创建最多八个独立副区；新副区默认 40×64、纵向，可各自修改为横向／纵向和 20–240 列、10–256 行。旧关不会自动扩大高度。尚未编辑的空副区可以移除。

门、锁门、P 门、普通管道及传送箱可选目标区域和出口坐标。普通管道四种方向均按实际管口进入；未配置跨区目标时保留原同区连接。选中跨区元素后，顶部显示目标与坐标，打开 **轮廓范围** 可在场景右上查看出口附近的缩略预览。不存在的区域和越界坐标会报错，**定位错误** 定位当前区域的元素。

跨区门仍按上，锁门消耗一把钥匙；P 门检查 P 时间；一次性传送箱使用后失效。进出冷却防止同次按键立即往返。出口坐标表示人物左上角，请预留对应形态的空间。

| 状态归属 | 处理 |
| --- | --- |
| 形态、装备及次数、得分、金币、钥匙、条件击败进度、生命、倒计时 | 关卡共享，跨区保留 |
| 被破坏的砖、怪物、地面物品、P／ON 状态、机关、已使用传送箱 | 区域独立，离开时缓存，返回继续；未激活区域的普通运动暂停 |
| 抱持／坐入的对象 | 同一个实体迁移到目标区，从源区移除；冻结计时不复制，持物暂停解冻 |
| 龟壳车 | 留在原区，玩家出入区域前结束驾驶 |
| 检查点 | 记录所属区域、位置与旗帜；死亡重建全部区域并回到该检查点，清空临时物品及装备 |

水位／岩浆可选上升、下降、循环及列范围；行号向下增加，因此最低液面行号大于最高液面。液面连续运动，仅在跨行时更新所管理的液体格，保留地形与区域外手绘液体。

默认镜头保持居中跟随及边界限制。可选横／纵自动滚屏，放置 **镜头路线** 后编辑折线路线；路线速度覆盖区域滚屏速度。**镜头停止区** 在人物位于范围内时保持镜头；离开后继续。滚屏落后边缘会造成失败；通关动画恢复跟随。

有限生命默认关闭；打开后初始 1–99 条，死亡只扣一次，即使立即 R 重试也不会漏扣；用尽后 R 开始新一局。普通 1UP 在无限试玩中改给 1000 分。大金币分别计入 10／30／50 枚真实金币，有限生命每满一百枚加一命，视觉粒子不计数。倒计时 0 为不限，最高 999 秒，跨区连续，超时失败；通关剩余每秒换 50 分，仅结算一次。

检查点可配置接触时形态或保持原样；终点可配置 1–24 格旗杆和顶端生命奖励。未配置时仍使用原九格旗杆、原高度计分与滑旗／庆祝／进城动画。

## 验证与参数

规则在 `rules/p2-*.ts`，编辑设置在 `editor/p2-settings.ts`，绘制在 `rendering/p2.ts`，示范在 `rules/p2-levels.ts`。新地图字段均为可选，不迁移或修改经典四关。

验证入口：`npm run typecheck`、`npm test`、`npm run build:target -- game:whale-maker`；实机脚本为 `verify-p2-browser.mjs`，同时回归 `verify-p0-browser.mjs` 与 `verify-p1-browser.mjs`。截图及报告写入 Games 的 `artifacts/whale-maker-p2/`，P2 单测为 `games/test/whale-maker-p2.test.mjs`。

本次验证结果：P2 专项 **59/59**，全库 **1166/1166**，类型检查与本游戏构建通过；浏览器 P2 **20** 项、P1 **20** 项、P0 **17** 项通过，均无浏览器控制台错误或未处理异常。已检查首领完整轮廓、五类装备叠加、跨区入口预览与 HUD 截图。构建保留原有 `adventure → expansion → adventure` 循环依赖提示。

这里的飞行秒数、预警、耐久、攻击次数和运动速度是本项目可玩的默认参数，不宣称为任天堂逐帧常数。穿戴类别及风格范围参考任天堂的[最终更新说明](https://play.nintendo.com/news-tips/news/super-mario-maker-2-free-final-update-details/)与[零件对应风格表](https://www.nintendo.com/jp/switch/baaqa/pc/make/ver.html)，美术保持鲸屿原创设计。
