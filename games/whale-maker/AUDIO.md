# 音乐与音效

新增原创轻快 BGM「珍珠海风 / Pearl Breeze」和 37 种音效，均在本地离线合成，使用 Haiyue 公开的 `@haiyue/engine/experimental/audio` 混音器播放。没有使用外部录音、采样包或现成曲目。

音乐为 C 大调、128 BPM、4/4 拍、32 小节，时长 60 秒，以木琴、拨弦、柔和贝斯、轻鼓点和沙锤组成四段编曲。音符与回声尾音绕回循环开头，接缝不加静音或淡出。编辑器内继续播放，并降低伴奏音量。

首次点击画面或按键后开启声音。右上角「音乐开 / 关」和「音效开 / 关」独立控制，M 切换音乐、N 切换音效；设置在重试、换关和编辑器切换时保留。暂停、失焦、页面隐藏和系统返回菜单会暂停音频；继续游戏从原音乐位置恢复。进入失败和通关动画时停止 BGM，播放相应提示音乐。退出游戏会关闭音频上下文并释放所有声音节点。

| 类别 | 事件 |
| --- | --- |
| 动作 | 普通跳、反墙跳、旋转跳、空中翻转、落地、脚步、滑行 |
| 收集 | Token 金币、奖励冒出、成长与火焰/巨型道具、无敌星、钥匙、检查点 |
| 战斗 | 发射火球、火球命中、踩怪、消灭敌人、踢龟壳、受伤、铁盆碰撞 |
| 持物 | 拿起、轻放、投掷、戴盆和坐盆 |
| 机关 | 横纵弹簧、水花与蹬水、管道、门、P / 红蓝开关、POW、石头落地、炮塔、融冰 |
| 结算与编辑器 | 失败提示、触杆与胜利音乐、按钮点击、绘制和擦除 |

游戏规则只产生有序事件，声音由独立音频层消费；反复按空中跳不会凭空播放成功跳跃的声音。相同事件限频，大量消灭敌人或同时碎砖不会叠加成过响的声音；画面外的普通音效不播放，画面内的效果随横向位置轻微左右偏移。最多 16 个声音同时播放，音乐只有一个循环声部。暂停和重试会丢弃过期音效。
