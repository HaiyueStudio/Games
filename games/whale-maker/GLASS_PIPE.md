# 连续透明管道

透明管道沿碰撞圆弧中心线以统一管径绘制，两个开口保留生成的玻璃口沿素材。角色按每秒 6 格沿管道中心线连续移动，弯头处平滑转向，使用专用穿梭帧；两套角色各有普通和双手捧物两组四帧。成长形态保持等比缩放。玻璃前层覆盖在角色与持物上，能看到角色在玻璃里面穿行。

站在上开口按 S/下进入；在下开口按 W/上进入；靠近侧开口按朝管内的左右方向进入。从畅通的开口可进入，管内沿整条管线自动行进。到达出口前检查实体砖和实物障碍：出口堵住时在管内掉头，沿原来的弯管连续返回，并从原入口离开；持物和敌人运动保持正常。若途中出口打开，可直接穿出。出口有离管动作和短暂重入冷却。普通管道仍使用自己的传送规则。

编辑器左侧选择玻璃管道，再点击地图放置一根完整 U 管。点击管道任意位置选中整根管线，右侧箭头控制末端：同方向延长，垂直方向增加弯头，反方向缩短或撤回一段。「延长」「缩短」沿当前末段调整长度，缩短到最短长度时停止；「撤去末段」可逐步退回直管。转弯会自动留足弯头空间。新段超出地图、与管线自交或占用其他机关时不会修改草稿，可用撤销恢复已完成的修改。整管支持框选、拖动、复制粘贴、删除和 JSON 存档。

第三张「机关试验海岸」的左侧阶梯可登上透明 U 管。旧版本相同编号的两根分离玻璃管道，在试玩或载入编辑器时会补成一根连续管道。

关卡保持 JSON version 1。起点使用 `glass-pipe`，其余占用格为 `glass-body`，起点属性中的 `path` 保存相对于该起点的整数格坐标，例如：

```json
{"path":[[0,0],[0,3],[15,3],[15,0]],"plant":false}
```

起点在第一段的左上格，中心线节点位于该格右下方一格处。路径首点必须是 `[0,0]`，只允许正交线段，不允许自交；两端线段至少 3 格，两个弯头之间至少 5 格。`plant` 控制第一端朝上开口的食人花，`endPlant` 保留旧关卡另一端的食人花。编辑和复制移动使用相对坐标，不会让出口留在原地。

美术通过内置 image_gen 生成，源 PNG 像素与透明通道保持不变。UV 测量和运行时取样去除接头的端口边线，不改源图。
