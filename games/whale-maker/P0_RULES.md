# P0：规则兼容、奖励与冻结生命周期

对应开发目标 01–03。实现日期：2026-10-29。

## 试玩与编辑

游戏底部的 **P0 冰晶试验** 可直接打开示范关。依次包含冰花、普通滑冰砖、装金币／敌人的封冻块、火花、带掉落的敌人、水域、砖台、门、弯曲透明管道、管花、炸弹、铁壳龟、铁盆和横弹簧。先冻住砖台上的敌人，Shift 抱起，按上过门，松 Shift 轻放或按 J 投掷；返回也可试验透明管道。冰花仍是本项目保留的跨系列扩展。

编辑器未选中对象时，右侧显示规则按钮；点击切换新规则／旧关兼容预设，支持撤销和重做。点击敌人，右侧可将掉落设为无、Token 金币或钥匙。掉落配置支持复制、移动、保存和读取。元素名称旁显示“3D 基础”或“保留扩展”；这表示设计来源，不表示已经实现参考游戏的全部特性。

普通滑冰砖在“砖块及路径”分类的末页。旧 `ice` 工具改名为“封冻块”，保留原内容编辑入口。两者都有光滑惯性开关；普通滑冰砖使用较实的冰纹和白色标记，封冻块保持半透明并显示内部物品。

## 01：旧图兼容与交互表

关卡仍使用 `version: 1`，新增可选配置：

```json
"rules": { "revision": 1, "rewards": "score", "freezing": "timed" }
```

| 情况 | 击败奖励 | 冻结／冰球 |
| --- | --- | --- |
| 新地图、内置示范、从菜单开始经典闯关 | 得分，不自动加金币 | 计时解冻；冰球有限反弹 |
| 旧存档没有 `rules` | 原来的普通击败 1 金币、壳击 2 金币 | 原来的永久冻结和冰球弹道 |
| 已有 `rules` 的保存／导入／重试／下一关 | 保留所选行为 | 保留所选行为 |

导入不默默改写旧图。只保留奖励与冻结两项兼容配置，不为每个机关增加一套规则模式；不支持的修订号和无效配置会拒绝载入。

`rules/interactions.ts` 覆盖现有 14 类敌人的抗性和攻击结果，独立列出原创 Boss 和机关接触。普通怪的击败、龟类缩壳、尖刺旋转跳反弹、炸弹点燃／踢出、火球解冻、冻结、分层损伤及碎冰使用不同结果。开关触发、POW 坐击／壳击、弹簧顶部／侧面和两类冰砖也明确区分。射击、旋转踩刺、头盔顶击等调用点已接入，其他旧碰撞分支按目标要求逐步迁移。

统一击败入口先检查存活状态，再发放奖励和掉落。同一帧多次接触不会重复奖励。既有砖缝双顶、横弹簧顶部站立、铁盆轻放与静止拿取、戴盆顶敌、独立食人花下落、堵塞管口返程继续保留。

## 02：金币、得分和掉落

- 实际拾取一个 Token 金币才增加金币计数，新规则同时加 100 分。金币飞向嘴部、击败散落光粒等纯动画不会再次计数。
- 普通击败起始 100 分。空中连续踩踏、同一滚动壳／投掷物连续命中、同一无敌星期间连续碰敌分别累计连击。
- 项目计分梯级为 100、200、400、800、1000、2000、4000、8000，之后封顶。踩龟使其缩壳也增加踩踏得分，但不提前释放击败掉落。
- 踩踏连击落到实际支撑面时结束。壳击按每件武器独立累计，再次踢／扔时重置。星连击在上一次星效果到期后重置；仍在同一星效果期间补吃星可延续。
- 配置掉落在实际击败时生成一次实物，需要再拾取。金币与钥匙不使用击败特效代替；冻结／解冻本身不奖励或掉落。物体自然消失和炸弹自爆属于消耗，不发放击败掉落。
- 掉落沿用 128 个实物的容量上限，满额时不挤掉玩家正在抱着的物体；掉出场景底部的金币／钥匙会清理。连击提示最多保留 12 条，1 秒后结束。
- 得分和最近连击由引擎 GUI 显示；敌人、金币、冰冻物和特效仍用普通 2D 渲染。重试恢复地图、配置掉落和敌人，并清空本次得分、金币及连击。

## 03：三种冰的身份与结束方式

| 对象 | 火球 | 移动／结束 |
| --- | --- | --- |
| `ice-solid` 普通滑冰砖 | 不融化 | 固定地形，可关闭光滑属性，无内部内容 |
| `ice` 封冻块，包括旧图中空的冰砖 | 融化，释放既有内容 | 保持原存档含义；内部金币不旋转 |
| 冻结敌人 | 解冻，不直接击败 | 保留冻结前身份，可计时解冻、搬运或碎裂 |

新规则冰球使用独立速度与弹道，落地反弹一次，再次落地碎裂；侧撞、命中及离开有效范围也会清理。火球保留原来的连续地面反弹。冰球可消灭跳跃火焰，对原创 Boss 只扣血，不冻结。

冻结时保存完整敌人状态，包含原种类、尺寸、方向、管口、飞行范围、鱿鱼阶段和铁壳身份。普通冻结时长为 **6 秒**，剩余 **1.2 秒** 开始晃动闪烁；空中冻结先停留 **0.6 秒** 再下落。以上是本项目可调参数，不作为马里奥原版精确数值。

- 抱持暂停解冻计时。轻放／投出后在当前位置恢复计时；过门、过普通管道、过透明管道均保持同一个实体与持物引用。未抱持对象的计时在视野外和玩家转场中继续。
- 水中冻结物向水面浮起，仍有碰撞和支撑；接触水时暂停解冻，离水后恢复。旧兼容规则保留原有行为。
- 投掷冻结物能击败普通敌人，侧撞普通砖会破砖并碎裂，撞墙碎裂；高处重落地和角色坐击也会碎裂。普通站立不会击碎。
- 管花原地冻结后仍固定于管口，解冻恢复四向管口关联。新规则不能把管花从管口抱走；旧规则已允许的搬离保持兼容，搬离后在当前位置变为独立食人花。
- 冻结炸弹暂停引信；恢复时从原剩余引信继续。反复冻住／解冻不产生得分和掉落。死亡重试不保留冻结计时、飞行冰球或持物引用。
- 游戏暂停由应用停止规则步进，所有冻结计时一起暂停。解冻预警、冰球爆裂和碎冰沿用现有冰晶素材及冰音效；本轮没有新增图片文件。
