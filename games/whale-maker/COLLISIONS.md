# 红蓝机关与碰撞修正

- 红蓝砖从虚线变成实体时，击败实际重叠的怪物，并清除重叠的道具与正在弹出的奖励；仅贴边的对象不受影响。抱持、乘坐中的物体被清除时，同步解除引用。所有按头顶、火球、龟壳等触发的开关共用这条规则。
- 开关替换为小方块 ON / OFF 素材：红色 ON、蓝色 OFF，游戏和编辑器共用。原图为 `assets/switch-blocks.png`，运行时打包到 `assets/runtime/mechanics.png` 的第 0、1 帧。由内置 image_gen 生成，[完整提示词](assets/switch-blocks.provenance.json)。
- 火球在普通砖、奖励砖、红蓝砖顶部继续弹跳；撞砖侧面时爆炸消失，撞底面时向下反弹。接触冰砖仍可融冰，碰撞面之外相邻的冰砖不会误触发。
- 高速龟壳撞到 POW 会引爆；静止龟壳不会因贴边引爆。投掷 POW 命中首个敌人、落地或撞墙均会引爆，范围震杀规则仍只作用于屏幕内地面敌人，普通踩踏仍不会触发。
- 两枚炮弹可以相向穿过或同向超越，保持原速度，不互相推挤、转向或卡在中间。
- 铁甲龟面朝运动方向。保留原画的头部、铁壳和足部，将足部与躯干分层取样；四足采用每秒 12 相位、共八相位的等幅步态，所有部件统一比例，静止时停止摆脚。图集 `assets/runtime/iron-parts.png` 是既有 `devices.png` 的局部取样，原图像素不变。铁甲龟新图生成持续返回 HTTP 429，因此实际交付使用现有原画分层动画，没有使用失败的生成输出。
- 多格炮台顶部下移 0.16 格，衔接底座。普通管口原图跨过图集分格边界，现在完整取样管口与领圈，按原始比例绘制，管身继续循环贴图。管口椭圆中心对齐站立平面。

规则回归：`games/test/whale-maker-collisions.test.mjs`。实际 WebGPU 验证：`node games/whale-maker/verify-collisions-browser.mjs`，截图输出到 `artifacts/whale-maker-collisions/`，含八相位铁甲龟、左右朝向、管口和炮台，以及各类碰撞过程。
