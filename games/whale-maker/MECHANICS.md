# 机关与水域扩展

沙漠远景、可摆放笑脸云、流沙、叠层仙人球和雪球见 [沙漠更新](DESERT.md)。流沙按实际埋入深度处理人物、敌人及实物，超过半格后跳高减半；雪球可推、抱、投掷及撞砖。

鱿鱼两段运动、顶砖引爆 POW 及冰面制动再次加倍见 [鱿鱼、POW 与冰面更新](SQUID_POW_ICE.md)。

弹簧实物反弹、珍珠重力、敌人/珍珠踩 P 开关及普通管道四向旋转见 [实物与管道更新](OBJECTS_AND_PIPES.md)。其他机关规则见 [火焰机关城更新](ADVANCED.md)：松开 Shift 轻放、按开火投掷；铁盆受击掉落后消失；石头按垂直于攻击方向的距离判断，2 格内触发。

第四张「藤蔓秘境」展示铁盆碎砖、隐藏钥匙、锁门、藤蔓、三个方向的石头和两种尖刺。门打开的画面向下补偿 0.1 格，底座与地面贴合。钥匙数量也在引擎 GUI HUD 显示。

P 计时结束时，仅还原尚未收集或打碎的转换格，已消耗的格子保持为空。死亡重试从蓝图重建，清理 P 转换、无敌星、头盔、弹簧效果、持物、门和镜头震动，保留检查点点亮记录。

编辑器左上箭头翻页选择元素，宝物块右侧也可翻页选择内容。单选、框选、拖动、复制粘贴、撤销、保存和 JSON 导入导出都会保留机关配置。导入上限 2 MB。

关卡可选 `properties` 按 `行 * width + 列` 的十进制索引保存：

```json
{"properties":{"123":{"length":6,"speed":-1.5,"phase":0},"456":{"link":2},"789":{"mode":"fixed"},"999":{"link":3,"plant":true}}}
```

`length/speed/phase` 用于火滚；`link` 用于门或普通管道；`mode` 用于独立食人花；`plant` 用于管口。普通管道的 `warps` 显式出口优先于连接编号。透明管道保存相对起点的正交 `path` 折线，沿实际管线出入，不使用传送出口。详见 [连续透明管道](GLASS_PIPE.md)。

`direction` 为石头的 `left | right | down`，默认向下；石头左上角保存 `stone`，其余三格为 `stone-body`。隐藏砖为 `hidden-block`，同样使用 `contents`；新增钥匙内容为 `key`。死亡重试恢复隐藏砖、钥匙、门锁和石头初始位置。
