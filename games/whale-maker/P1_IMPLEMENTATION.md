# P1 实现与试玩说明

2026-10-29，交付路线图目标 **04–15**。游戏场景继续使用普通 2D 精灵渲染；HUD、触屏按钮和编辑器使用 Haiyue Engine GUI。经典 1-1～1-4、原有形态、铁盆、冰花、巨型珍珠和流沙保留。

## 试玩入口与操作

游戏底部 **「P1 试验工坊」** 每次点击切换下一张独立示范关，共七张。切换会重新开始该示范；已有草稿请先保存或导出。

| 搬运与液体 | 箱内钥匙、浮箱、水与岩浆、大小雪球、冰冻、门和透明管道、流沙 |
| 3D 动作训练 | 蓄力越墙、低顶远跳、高旋转跳、树与半实体平台 |
| 猫爪攀爬 | 猫铃铛、爪击翻壳、有限攀墙、树顶钥匙与锁传送箱 |
| 回旋镖弯管 | 回旋镖往返、金币／敌人／开关联动、敌人与奖励走弯管 |
| 建造锤工坊 | 锤击硬砖、造箱、骷髅龟、感叹号砖与红 POW 连锁 |
| 开关运输解谜 | 输送带、刺砖、三种弹床、蓝蛇砖、路径砖、粉红钥匙币和锁门 |
| 敌人与雪地 | 巨大／翅膀／降落伞变体、新敌人、雪地生成、鱼骨与金币条件 |

原有移动、跳跃、X 旋转跳、空中下坐、Shift 快跑／抱起／松开轻放、J 持物投掷继续有效。新增：

| 输入 | 动作 |
| --- | --- |
| 地面按住下约 0.7 秒，再跳 | 蓄力高蹲跳 |
| K + X | 高旋转跳，与普通 X 旋转跳分开 |
| 下 + K | 翻滚，撞墙、结束或拿起物体时取消 |
| 翻滚中跳，或快跑时下 + 跳 | 低轨迹远跳 |
| 持续快跑约 2 秒 | 新规则关卡进入第二阶段加速 |
| 猫形态 J／空中 K | 爪击／扑击 |
| 猫形态贴墙按上 | 有限时间攀墙、半实体墙和旗杆；落地恢复体力 |
| 回旋镖形态 J | 投出、返回并接回，同一时间一枚 |
| 建造锤形态 J／L | 挥锤／在身前造箱，最多五个活跃建造箱 |
| 树旁按上／上下／跳 | 抓树／攀爬／跳离，到树冠释放内容一次 |
| 传送箱内按上 | 使用配对传送箱；锁箱消费一把钥匙，两端用后失效 |

触屏新增 K、L 按钮；现有方向、跳、旋转、抓取、开火按钮可组合操作。手柄新增 LT→K、RT→L，原映射保留。小型和长高状态宽 0.9 格，巨型宽 1.9 格；新增三形态宽 0.9、高 2 格，受伤退为长高状态。

## 编辑方法与兼容

左侧原有敌人、地形路径、道具、装饰分类已包含新增元素。选择元素后右侧可切换 **「高级／条件」** 和 **「内容／基础」**。数值输入后按 Enter 提交；上一页／下一页查看其余属性。框选支持修改所有选中对象都具有的合法属性；不支持的字段不会写入。

选中带路线对象后，打开「路径编辑」用四向按钮延长、转弯或撤去末段；开启轮廓后可直接拖动节点。修改保持折线路径正交并检查边界，失败保留原地图。缓坡两半、旧炮台／仙人球的完整占格以及有尺寸的新平台均参与选择、复制、移动和撤销。

未选对象时，高级面板配置玩法主题与通关条件。远景仍在基础面板独立选择。通关条件与检查点冲突时，点击「定位错误」选中对应检查点并移动编辑镜头；保存／导入时同样校验。

`version: 1` 不变，新字段均可省略：`theme`、`condition`、元素 `properties`，以及 `rules.pipes`。P0 的得分与冰冻兼容配置保持独立。没有 `rules` 的旧图仍使用旧金币奖励和永久冰冻；已有三字段 `rules` 未指定 `pipes` 时仍保留旧管道策略。

- `pipes: 'legacy'`：保留横口空中进入、堵口返程。
- `pipes: 'reference'`：横口需站稳进入；入口可进入但途中两端都封闭时受困失败；超过管径的持物不能进入。
- 新关默认参考规则；经典图和导入旧图不被强制改写。
- `properties.liquid` 记录编辑时被实体覆盖的水／岩浆／流沙格，加载和重试恢复底层液体。

普通管道颜色的默认生成间隔：红 1.2、绿 1.8、蓝 2.4、黄 3.6 秒；显式 `period` 优先。其他可调参数包含尺寸、路线、速度、启动方式、范围、数量、弹速、落地震波、掉落等。大型冻结敌人的现代解冻计时为 3 秒，普通为 6 秒。这些数值以及猫攀爬 1.8 秒、造箱上限 5 个均为本项目参数，不声称是原版精确常数。
