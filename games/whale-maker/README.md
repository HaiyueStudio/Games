Haiyue 公共 API 制作的 2D 横版平台游戏与关卡编辑器。场景、角色、敌人、道具和编辑网格使用普通 2D 精灵渲染；HUD、按钮和触屏控制由 Engine GUI 叠加到同一个 WebGPU canvas，没有 DOM HUD。鲸鱼娘包含站立、跑步、跳跃、旋转、蹲下、发射、捧物、游泳与滑坡动作；敌人包含咕咕嘎嘎、珊瑚龟、尖刺龟、食人花、鱼、鱿鱼和跳跃火焰。

珊瑚地形按相邻关系绘制连续土层，只在露出的上表面铺草皮；上下叠放不重复草皮，连续路段没有透明拼缝。左右斜坡使用与碰撞线一致的实心三角形，与相邻斜坡、平台和下方土层衔接；底部与背面也有碰撞。土层与草皮取样自已有生成素材，源 PNG 不变，游戏与编辑器共用绘制逻辑，地图中真正留出的沟壑仍保持为空。

`rendering/WhaleScene2D.ts` 使用公开的 `@haiyue/extensions/experimental/indexed-sprite` 2D 精灵批处理器，支持 RGBA 图集、翻转、缩放、透明混合与画面裁剪，manifest 已显式标注实验性依赖。场景位置每帧通过 2D 绘制命令提交，不依赖 GUI 布局或重绘标记。GUI 使用独立的后置叠加通道。

从 Games 运行 `npm run build:target -- game:whale-maker`，再运行 `python -m http.server 8080 --bind 127.0.0.1`，打开 `http://127.0.0.1:8080/games/whale-maker/index.html`。也可从大厅选择「鲸屿制造」。开发时用 `npm run dev -- game:whale-maker` 监听构建，HTTP 服务需单独启动。

- A/D 或左右：移动，约 0.18 秒从起步加速到匀速步行；按住 Shift 快跑，上限为步行的约 1.55 倍，松开恢复步行。Space/Z：普通跳跃；X：旋转跳跃；S/下：地面下蹲、空中翻筋斗后向下坐击。贴墙再按跳跃可反墙跳。
- 快跑中按下 S/下，在平地保留前进惯性并逐渐减速，约 0.7 秒滑行三格后停稳；继续按住下保持蹲姿，松开可重新起步，跳跃或撞墙可中断滑行。斜坡继续沿坡下滑。Shift 同时保留抱物操作，松开轻放，拿着时按 J 投掷，持物时也可以快跑和蹲滑。
- 行走、快跑和滑行会从脚底扬起浅色烟尘，快跑更密、滑行更大；尘团留在经过的位置，膨胀、上浮并在 0.48 秒内淡出。烟尘使用普通 2D 粒子绘制，空中、水中和顶住墙静止时不产生，重试时清理。步态动画按实际移动距离推进，快跑时步频同步加快。
- 下蹲切换专用蹲姿，脚底固定，降低碰撞高度；松开按键时若头顶有砖块则保持蹲姿，离开低矮空间后恢复站立。下蹲时可缓慢移动，也允许保持蹲姿跳跃；管口按下仍优先进入管道。
- 四种服装均使用独立下蹲素材，与同一形态的其他动作保持相同绘制比例；身高降低来自蹲姿本身，不压扁图像，普通、成长和巨型状态均保持脚底对齐。
- 按住跳跃时上升重力较低，松开后上升重力增加，按键时长连续控制跳高；再次按键不能在普通空中续跳。落地前约 0.13 秒按跳会缓冲起跳。地面松键保留惯性，空中可调整方向；反墙跳短暂保留向外速度。镜头跟随角色中心，并在边界处夹紧。
- 旋转跳以每秒 16 帧播放右侧、正面、左侧、背面四张独立角色帧，一圈 0.25 秒；落地和重试时复位。
- 成长珍珠：变大、顶碎贝壳砖；火珊瑚：升级红色火球发射（J）。宝物块先弹出内容，道具冒出后才能拾取；自动成长会根据当前体型弹出成长珍珠或火珊瑚。
- 发射包含蓄势、出手、收手三帧，出手时生成红色火球并显示枪口闪光，动作持续 0.24 秒。短按也会完成一次发射；朝向在开始发射时确定，支持地面、空中和下蹲发射。
- 小体型顶贝壳砖时，砖块上弹后复位；大体型或小体型戴着铁盆时顶碎砖块，显示碎片，碎砖不消耗铁盆。顶贝壳砖或未使用的宝物块时，站在被顶方块上的敌人会旋转震飞并消灭，小体型和成长形态均有效。宝物块使用后变为空块。顶到两块砖的接缝时，实际接触到的两块同时响应：一起上弹、分别碎裂，或各自弹出配置的奖励/敌人；跨在两块砖上的敌人只消灭并计分一次，没有碰到的相邻砖块不触发。
- 管道有实体碰撞。站在带旋转金币标记的管道口按 S/下，可以进入秘密金币区；右侧管道同样按下返回。进入与出管各有渐隐、下沉和浮出的过渡。
- 踩龟缩壳；接触静止龟壳踢出；按住 Shift 接触静止壳可抱住，松开轻放，J 投掷。抱着龟壳正面接触敌人时，龟壳与该敌人同时旋转上抛并消失，角色不受这次正面碰撞的伤害；背面仍按正常规则受伤。旋转踩踏可打碎龟壳。飞行龟壳能击败敌人，也会撞碎侧面接触到的贝壳砖、散出碎片并反弹；静止、抱住或缓慢移动时不碎砖，宝物方块、地面和管道仍保持实体碰撞。
- 怪物与未抱起的龟壳有实体体积。普通怪物相遇会分离并向外转向，追上同向怪物时由后方怪物转向；静止龟壳留在原地挡路，露出的食人花也会阻挡路线。上下接触会阻挡穿透，落下的怪物可停在另一只怪物或龟壳上；分离时同时检查地形，不会把怪物挤进墙或斜坡。已消灭、抱起或尚未露出的食人花不参与普通阻挡。飞行龟壳保留攻击效果，两只飞行龟壳相撞则一起被击碎。
- 踩怪时按住跳跃可高弹，踩中前约 0.13 秒按下可缓冲；未按键时轻弹，踩中后 0.12 秒内再按跳也能起跳。踩怪后的跳跃同样支持按键时长控制高度，支持普通跳和旋转跳。
- 踩踏消灭敌人时缩小并散出Token金币；火球、飞行龟壳击中敌人时，敌人旋转上抛、落下并淡出。效果独立于碰撞状态，最多保留 48 个，0.75 秒后清理。
- R 重试，P 暂停，E 切换编辑器/试玩。死亡重试时从关卡初始蓝图重建砖块、宝物方块内容、金币、敌人及其位置；角色仍从检查点重生，保留死亡次数，本轮金币与计时归零，清空弹丸、抱壳和所有临时效果。触碰终点旗杆判定通关。
- 检查点旗面每秒 12 帧循环飘动，未经过时为灰色；首次接触后点亮为彩色，旗杆围绕底座来回晃动并在 1.1 秒内停稳。角色播放 0.8 秒的惊喜、举手、欢呼和收手动作，配合轻跃，期间仍可移动和跳跃。站在旗旁不会反复触发；多个检查点分别记录点亮状态，最后激活的位置用于重生。死亡重试保留已点亮的旗子，重新开始或重新试玩关卡则恢复灰色。
- 抵达终点后锁定移动，角色滑下旗杆后开心跳起，再轻跳一次，周围散出旋转金币；随后自动走入城堡并显示通关提示。镜头继续居中跟随并限制在场景边界，滑旗、庆祝和后续行走时保持角色可见；各形态均支持，R 可立即重试。
- 失败先短暂停顿，切换眩晕姿态，上抛后落下，再显示变暗与滑入的失败提示。角色和敌人全部使用等比缩放并以脚底对齐，鸭子、龟各有四帧行走动画。

可选 `contents` 对象以十进制单元格索引（`行 * width + 列`）为键，值为 `auto | coin | growth | fire | duck | turtle | empty | spring-v | basin | pow | p-switch | star | plant | fish | squid | spiky | key`。允许配置 `?` 或 `hidden-block` 格；省略时使用 `auto`。移动、复制、删除和撤销同时处理内容元数据。管道渲染取样避开拼块内部描边，管身连续绘制，不再逐格重复上下黑边；碰撞仍使用原来的两列网格。
