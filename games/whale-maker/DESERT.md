# 沙漠、流沙、仙人球与雪球

「切换示范关卡」新增第十一张「金字塔流沙与雪球」。也可以在编辑器取消选取后，从右侧背景列表选择「沙漠金字塔」。远景包含分层沙丘、带明暗面的金字塔与太阳，随镜头轻微视差移动。海岸自动笑脸云的锚点从 12 个减少为 4 个，当前画面通常只出现一两朵；「装饰」分类新增「笑脸云装饰」，可自行摆放，不产生碰撞。

在「装饰」分类选择「流沙」，像水域一样连续涂绘，最上层自动显示流动沙面。人物站在流沙上每秒下陷 0.25 格；有水平位移时减为每秒 0.125 格。埋入超过 0.5 格后，起跳速度按平方根折算，使相同按键时长下的跳跃高度约减半。人物完全埋入时死亡，铁盆、无敌时间与无敌星都无法防止窒息。敌人、滚动珍珠与实物道具共用下陷规则，完全埋入后消失；实际砖台、箱子等支撑仍会阻挡继续下沉。流沙前层遮住实际埋入的部分。

在「敌人」分类选择「仙人球」。底部格为锚点，默认 3 层，选中后在右侧调整 1–8 层；可作为一个对象移动、复制、删除和撤销。最上层有脸与花朵，是头部；火球或冰弹打中头部直接击败整只，打中身体只去掉一层并播放头部落下和碎片效果。每秒移动 0.6 格，碰到障碍转向。普通踩踏有伤害，旋转跳可安全反弹。

在「道具」分类选择「雪球」，也可设为宝物块或炮台内容。雪球为一格实体，可阻挡敌人、承托人物，也可通过人物接触向前推动。Shift 抱起，松开轻放，J 投出；投出后以每秒 8.5 格滚动，与人物快跑上限相同。滚动或抱着撞到普通敌人时，雪球破碎并击败接触到的敌人；碰到砖墙会破碎，并调用同一套顶砖反应，包括宝物、砖块上弹、顶掉砖上敌人和支撑的 POW。高处落下砸到砖也会触发，普通地面可正常承托雪球。

新增场景、敌人、道具与流沙表现均使用引擎普通 2D 渲染，HUD、分类图标和属性仍使用 Engine GUI。内置图片生成接口返回 429，未生成新位图；本轮使用原生 2D 图形及 SVG 图标完成画面，没有启用 CLI 图片生成。完整尝试提示词与美术来源见 `assets/desert.provenance.json`。

规则检查：`games/test/whale-maker-desert.test.mjs`。浏览器验证：`verify-desert-browser.mjs`，截图与测量输出至 `artifacts/whale-maker-desert/`。

类型检查、全量 1001 项规则测试和本游戏构建通过；最终流沙背景锚点调整后又通过 23 项沙漠/地形专项检查。新场景浏览器验证覆盖 18 项交互，原有冰火/角色 11 项和机关工坊 18 项回归均通过，无控制台错误或未捕获异常。实测静止每秒下陷 0.25 格、走动约 0.125 格。最终金字塔使用平滑三角形材质，示例检查中的绘制命令从 628 减为 394，仍合并为一次普通 2D 绘制调用；屏幕外的仙人球、雪球和碎片不提交绘制，关键截图已检查。
