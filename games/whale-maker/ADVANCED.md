# 火焰机关城更新

示范关卡按钮循环到第五张「火焰机关城」，可试玩红蓝机关、冰砖、炮塔、幽灵、铁壳龟、新水域和连续透明管道。规则独立于普通 2D 精灵绘制；HUD、编辑器及触屏按键使用 Haiyue Engine GUI。

## 操作

| 操作 | 效果 |
| --- | --- |
| 按住 Shift 接触可拿物品 | 双手捧起；同时保留 Shift 快跑 |
| 松开 Shift | 在身前轻放，初始水平速度为零 |
| 拿着物品时按 J / 开火 | 向前投掷，不会同时发射火球；不需要先松 Shift |
| 抱着铁盆按下 | 坐入铁盆，移动时低矮地一跳一跳前进 |
| 坐盆时按跳跃 | 带着铁盆正常跳跃，按键时长控制高度 |
| 坐盆时按住 Shift 再跳 | 跳出铁盆；盆留在原处 |
| 空中按下 | 先翻筋斗 0.22 秒，再向下坐击；支持向下顶砖、触发奖励及开关，直接打碎碰到的龟壳 |
| 水中按跳跃 | 两帧蹬水动作；单次上升高度为旧版 40% |
| 连续跑跳 | 落地后 0.28 秒内继续起跳可形成三段跳；第三跳比普通最高跳跃高 2 格 |
| 踩纵向弹簧 | 基础上升高度比旧版少 2 格；在弹起时按跳，可叠加普通跳跃最高高度 |
| 贴墙下降 | 举起手扶墙，保留反墙跳 |

坐在铁盆里可阻挡脚底方向的尖刺伤害，侧面的四面尖刺仍危险。铁盆静止时也会阻挡怪物路线。头盔受击时掉落的是会淡出的视觉效果，不会生成可再次捡回的铁盆；石头免疫仍有效。

## 机关与敌人

| 元素 | 规则 | 编辑器 |
| --- | --- | --- |
| 石头 | 向下攻击看玩家与石头中心的横向距离，左右攻击看纵向距离；3 格内警觉、2 格内启动，玩家须在攻击方向。普通侧面接触仅阻挡或推动，下压及被挤在障碍间才致命；铁盆免疫 | 2×2 整体对象，设置左、右、下 |
| 炮塔 | 默认发射可踩掉的可爱炮弹；空中炮塔会落下，压死正下方玩家或敌人；稳定后每 2.4 秒发射一次，朝玩家所在方向 | 高度 1–8 格；选择发射金币、成长/火力、可抱道具、钥匙或敌人；高度和内容随复制、保存、导出保留 |
| 害羞幽灵 | 玩家背对时以每秒 0.65 格缓慢追近；面对时停住并捂脸；漂浮时可穿越地形 | 单格放置，也可从方块或炮塔出现 |
| 红蓝开关 | 顶击、坐击或飞行物撞击切换颜色；红色状态红砖实体、蓝砖虚线，蓝色状态相反 | 分别放置开关、红砖、蓝砖；初始为红色 |
| 冰砖 | 在同一格放冰砖与金币或敌人即可冻结；冻结金币保持正面帧，不旋转；火球融冰后恢复内容并播放碎冰消散动画 | 冰砖覆盖已有金币/敌人，或把金币/敌人画在已有冰砖上；也可通过右侧内容面板配置 |
| 铁壳龟 | 火球不能击杀；踩中缩成铁壳。缩壳后计时 10 秒，静止或被抱着时重新钻出；高速移动的铁壳等停下后再钻出 | 单格放置，也可作为奖励或炮塔内容 |
| 鱿鱼 | 0.65×1.5 格碰撞体，快速上升、缓慢下降，使用新的四帧长身素材 | 在水域内放置 |

炮塔用底部 `cannon` 格作为锚点，上方为 `cannon-body`，`properties.height` 保存高度。`contents` 同样支持炮塔和冰砖；炮塔默认 `cannonball`，冰砖默认 `empty`。其余关卡 version 1 数据继续兼容。

## 火球与通关

火力形态两套角色换成红色服装，行走、旋转、发射、下蹲、抱物、蹬水、坐击、扶墙、吃金币和爬藤都使用对应的红装素材。火球水平速度为每秒 11 格，是上一版的两倍，保留加高的弹跳弧线；落到砖块或地面上会弹跳，撞到侧面或敌人后小爆炸消失。铁壳龟和铁壳会挡住火球。

终点为 12 格高、0.2 格宽旗杆和一格贝壳砖底座，碰到的高度越高，得分越高（100–5000）。角色抓住旗杆滑到底部，开心跳两次，再自动走入后方城堡并淡出，最后显示通关提示。

透明管道的碰撞和角色穿行路线使用圆弧弯头；角色穿行时敌人、道具、炮塔、火球和机关计时继续更新。普通管道使用新管口和可镜像循环的管身取样，长管每格重复材质，不再把管身整体拉长；管口显示位置使角色站在开口中间。
