# 地图协议 v1

根对象：`format: "haiyue-valley-map"`、`version: 1`、`catalogVersion: 1`、`id`、`name`、`objects`、`groups`、`opticalLinks`。标准编号见 `../maps/catalog.json`，完整结构见 `../maps/map.schema.json`，可玩示例见 `../maps/switch-garden.json`。

## 坐标与几何

- Y 向上，单位为格。`position` 是路径中心线的局部原点在世界中的位置；`rotation: [x,y,z]` 使用度，作用顺序为 Z → X → Y，与矩阵 `Ry × Rx × Rz` 对应。
- 一格普通路径默认 `length = width = thickness = 1`，是完整立方体；顶面 Y=0，底面 Y=-1。普通方块和机关平台的四个顶面边中点通过中心相连，支持在 X/Z 方向转弯；当前没有自由地面导航或物理碰撞。
- 楼梯从左端 Y=0 开始，到右端 Y=`rise` 结束，包含真实台阶高差。
- 5 号三棱柱是完整方块沿竖直对角面 `x/length = z/width` 切成的半块，`prismHalf: "a"` 占 `x/length ≤ z/width`，`"b"` 占另一半。两者都是直角三角形顶面、竖直侧面的三棱柱，体积各为原方块的一半。其位置原点仍是所切方块的顶面中心；角色停靠点位于各自三角顶面的重心。
- 扭转路径沿 X，截面从 0 连续扭到 `twist` 度；圆弧位于 XZ 平面，中心线为 `[radius*sin(a),0,radius*(1-cos(a))]`，`a` 从 `-arc/2` 到 `arc/2`。圆弧长度由半径和角度决定，不使用 `length`。
- 曲线路径采样 32 段，渲染及行走共用样本。角色的脚位于中心线，并随扭转后的曲面法线改变朝向。

默认构件的 X/Z 位置是整格中心，Y 是行走面参考高度。复制偏移整格，拖动按锚点的绝对位置吸附；多选拖动保持彼此偏移，Y 不变。「对齐网格」可将所选物体的 X/Y/Z 吸附到当前网格，支持撤销。导入保留旧地图的精确坐标，组轴心可以合法地处于半格。

## 分体方块

编辑器中选择未旋转的 1×1×1 普通方块，点击「拆为 A / B 三棱柱」。A 保留原 ID、位置和所属组；B 获得独立 ID，初始不分组，并沿默认等轴视线偏移 `[d,d,d]`。例如 A 位于 `[0,0,0]`、B 位于 `[3,3,3]`：它们实际不相接，但在默认等轴正交投影中仍组成一格完整方块。

两个半块都可以继续单独移动、旋转、归入不同物体组。导出保存两个独立的 5 号实例及其 `prismHalf` 和变换，用 `aEnd:4 / bEnd:4` 连接对角切面。它们不是完整立方体的重叠，也不是体积完整的楔形。切面投影及半块朝向不匹配时，角色不能穿越；只让切面中点重合不足以连接。

`split-cube.json` 是可通关的分体方块示例，用于验证这类不可能几何的基本拼接。旧 JSON 的显式长宽厚会保留；缺省 `prismHalf` 按 A 半块读取，不会自动缩放用户已经制作的地图。

## 配色与手轮

每个实例的可选 `colors` 包含五个 `#RRGGBB` 字段：`surface`（路径主体）、`hub`（中空轮毂）、`spokes`（方杆和转轴）、`tips`（四个末端方块）、`base`（墙面轴座）。旧 JSON 缺省时补入默认配色，导出总是保存完整配色。除 3 号旋转机关外，其余构件目前只使用 `surface`。

3 号手轮由八边形轴座、方转轴、中空多边形轮毂及四根方杆组成，固定安装在平台局部 Z+ 侧。可以修改物体旋转来改变安装方向。手轮围绕自身轴旋转，`motion.axis` 仍决定它驱动的道路/物体组运动轴。手轮装饰伸出格子边界，但不会改变路径顶面中心锚点或通行端口。

## 物体组与机关

组包含唯一 `id`、显示 `name`、世界空间 `pivot`。成员的 `position/rotation` 始终保存初始世界变换。运行时先应用成员自己的变换，再绕组轴心旋转，最后加组位移；不支持嵌套组。

3/4 号物体的 `motion`：`axis` 指定世界 X/Y/Z 轴；`min/max` 为相对初始状态的可拖拽范围；`step` 为松手吸附间隔；`targetGroup: null` 只驱动自身，填写组 ID 则驱动整个组。旋转值单位为度，平移值单位为格。角色行走、开关动画播放、关卡结束，或者角色位于被驱动对象/组上时禁止拖动。

8 号物体的 `trigger.actions` 示例：

```json
{
  "mode": "once",
  "actions": [{
    "groupId": "bridge",
    "translation": [0, 0, -3],
    "rotation": [0, 90, 0],
    "duration": 1.5,
    "easing": "smooth"
  }]
}
```

角色到达按钮中心才触发。`once` 每次试玩只触发一次；`toggle` 离开后重新踩入，在目标姿态和初始姿态之间切换。目标位移/旋转始终相对地图初始状态，不累加；每个开关最多 20 个动作，同一组不能重复。动作同时开始，可分别设置时长；`smooth` 使用平滑起止，`linear` 为匀速。如果组上有角色，角色随该组一起移动。新开关开始时暂停原有行走路线，动画结束后重新选择道路，避免沿旧路径走进空中。

多个开关可控制同一组，后触发者从当前姿态动画到自己的目标。拖拽控制同组时，其参数作为开关姿态上的额外位移/旋转。

## 错觉连接

`opticalLinks: [{a:"road-a",aEnd:1,b:"road-b",bEnd:0}]` 明确声明可发生视觉连接的端口：普通方块的 `0/1/2/3` 分别为局部 `X−/X+/Z−/Z+`；楼梯、圆弧、扭转道路只使用 `0` 起点和 `1` 终点；半块 A 有 `0/3/4`，半块 B 有 `1/2/4`，其中 `4` 是对角切面。世界距离小于 0.065 格的端口自动相连；显式错觉接缝还要求屏幕投影距离小于 0.055 格。默认等轴投影为 `u=(x-z)/√2`、`v=(2y-x-z)/√6`；视角旋转时使用引擎相机的实际右/上向量重新投影。普通画面重叠不自动成为路口。

跨越错觉接缝时改变角色三维深度而保持屏幕位置连续。每次选择道路都从当前姿态重建连通图；动画期间暂停选择新路线。编辑器与地图游戏均提供旋转视角和复位等轴视角；相机状态不写入地图 JSON。为避免跨缝过程中改变投影，角色行走或机关动画期间暂停视角旋转与复位。

## 校验与加载

最多 500 个对象、100 个组、1000 条错觉接缝。拒绝未知版本/编号、重复 ID、悬空组与端点引用、非有限数值及越界参数；ID 为 1～64 位字母、数字、下划线或连字符，并保留 `__proto__`、`constructor`、`prototype`。导入失败保留现有地图。Schema 校验结构，跨对象引用及 ID 唯一性由共享 `parseMap` 校验。

试玩要求恰好一个出生平台、至少一个出口，并且所有开关有有效的非空目标组。运行时可通过 GUI「载入地图」选择本地 JSON，或在游戏页面追加 `?map=./maps/switch-garden.json` 从同源 URL 加载。URL 模式也会进行相同校验。
