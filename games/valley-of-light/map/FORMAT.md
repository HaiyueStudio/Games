# 地图协议 v1

根对象：`format: "haiyue-valley-map"`、`version: 1`、`catalogVersion: 1`、`id`、`name`、`objects`、`groups`、`opticalLinks`。标准编号见 `../maps/catalog.json`，完整结构见 `../maps/map.schema.json`，可玩示例见 `../maps/switch-garden.json` 和 `../maps/seaside-garden.json`。

## 坐标与几何

- Y 向上，单位为格。`position` 是路径中心线的局部原点在世界中的位置；`rotation: [x,y,z]` 使用度，作用顺序为 Z → X → Y，与矩阵 `Ry × Rx × Rz` 对应。
- 一格普通路径默认 `length = width = thickness = 1`，是完整立方体；顶面 Y=0，底面 Y=-1。普通方块和机关平台的六个面各有独立的边中点及面中心通路，三棱柱同样支持其五个面；同一物体的不同面不直接相连，需要曲线路径改变朝向；当前没有自由地面导航或物理碰撞。
- 楼梯从左端 Y=0 开始，到右端 Y=`rise` 结束，包含真实台阶高差。
- 5 号三棱柱是完整方块沿竖直对角面 `x/length = z/width` 切成的半块，`prismHalf: "a"` 占 `x/length ≤ z/width`，`"b"` 占另一半。两者都是直角三角形顶面、竖直侧面的三棱柱，体积各为原方块的一半。其定位锚点仍是未旋转方块的顶面中心；旋转轴心是所在方块的几何中心，即相对 `position` 的 `[0,-thickness/2,0]`，A/B 半块共用这一轴心，不使用三棱柱自身的重心。旋转不改变所在方块中心；角色停靠点位于当前行走面的中心，三角面使用重心。
- 扭转路径沿 X，截面从 0 连续扭到 `twist` 度；圆弧位于 XZ 平面，中心线为 `[radius*sin(a),0,radius*(1-cos(a))]`，`a` 从 `-arc/2` 到 `arc/2`。圆弧长度由半径和角度决定，不使用 `length`。
- 圆弧另有可选的 `arcTwist`（-360～360 度，缺省 0），从起点到终点逐渐翻转截面，可以衔接侧面；旧地图缺省时仍为平面圆弧。
- 曲线路径采样 32 段，渲染及行走共用样本。角色的脚位于中心线，并随扭转后的曲面法线改变朝向。

默认构件的 X/Z 位置是整格中心，Y 是行走面参考高度。复制偏移整格，拖动按锚点的绝对位置吸附；多选拖动保持彼此偏移，Y 不变。「对齐网格」可将所选物体的 X/Y/Z 吸附到当前网格，支持撤销。导入保留旧地图的精确坐标，组轴心可以合法地处于半格。

## 分体方块

编辑器中选择未旋转的 1×1×1 普通方块，点击「拆为 A / B 三棱柱」。A 保留原 ID、位置和所属组；B 获得独立 ID，初始不分组，并沿默认等轴视线偏移 `[d,d,d]`。例如 A 位于 `[0,0,0]`、B 位于 `[3,3,3]`：它们实际不相接，但在默认等轴正交投影中仍组成一格完整方块。

两个半块都可以继续单独移动、旋转、归入不同物体组。导出保存两个独立的 5 号实例及其 `prismHalf` 和变换，对角切面会按实际变换自动识别，也保留 `aEnd:4 / bEnd:4` 显式连接。A/B 是局部几何定义，旋转后的两个 A 也可以构成互补接缝。它们不是完整立方体的重叠，也不是体积完整的楔形。切面投影及半块朝向不匹配时，角色不能穿越；只让切面中点重合不足以连接。

`split-cube.json` 是可通关的分体方块示例，用于验证这类不可能几何的基本拼接。旧 JSON 的显式长宽厚会保留；缺省 `prismHalf` 按 A 半块读取，不会自动缩放用户已经制作的地图。

## 配色与手轮

每个实例的可选 `colors` 包含五个 `#RRGGBB` 字段：`surface`（路径主体）、`hub`（中空轮毂）、`spokes`（方杆和转轴）、`tips`（四个末端方块）、`base`（墙面轴座）。旧 JSON 缺省时补入默认配色，导出总是保存完整配色。除 3 号旋转机关外，其余构件目前只使用 `surface`。

3 号手轮由八边形轴座、方转轴、中空多边形轮毂及四根方杆组成，未旋转时转轴方向与局部 `motion.axis` 一致：X/Z 安装在侧面，Y 安装在顶部。实例 `rotation` 会绕路径块的几何中心旋转整个平台、轴座和手轮，块中心保持在 `position + [0,-thickness/2,0]`；局部转轴随实例朝向及所属组一起变化。转轴穿过手轮路径块的几何中心（单位块在顶面锚点下方半格），所控制的道路/物体组绕这个中心旋转；不使用目标组的 `pivot`。手轮装饰伸出格子边界，但不会改变路径顶面中心锚点或通行端口。

试玩时必须按住轮毂或轮臂，以手轮投影到屏幕的中心为圆心绕动。角度取连续指针极角差，跨越 ±180° 不跳变，可正反向连续旋转任意圈数，角度持续累计，松手再按住仍从已有角度继续；径向拖动不转动；松手按 `step` 吸附。鼠标和单指触摸共用同一交互，取消手势恢复拖动前角度。

## 物体组与机关

组包含唯一 `id`、显示 `name`、世界空间 `pivot`。成员的 `position/rotation` 始终保存初始世界变换。运行时先应用成员自己的变换，再将开关姿态绕组 `pivot` 旋转并加上位移；之后按地图对象顺序叠加手轮旋转和平移机关。手轮的旋转中心来自控制它的路径块，组 `pivot` 仅用于开关动画。不支持嵌套组；机关轴心可以跟随其所属组，但不同组之间不能形成旋转机关的循环依赖。

3/4 号物体的 `motion`：3 号的 `axis` 指定机关自身的局部 X/Y/Z 转轴，实际驱动方向随机关朝向和所属组变换；4 号的 `axis` 指定世界 X/Y/Z 平移轴；`min/max` 仅限制 4 号平移机关相对初始状态的行程，3 号手轮始终连续旋转（旧 JSON 中的这两个字段保留但不作为旋转限位）；`step` 为松手吸附间隔；`targetGroup: null` 只驱动自身，填写组 ID 则驱动整个组。旋转值单位为度，平移值单位为格。角色行走、开关动画播放、关卡结束，或者角色位于被驱动对象/组上时禁止拖动。

8 号物体的 `trigger.actions` 示例：

```json
{
  "mode": "once",
  "actions": [{
    "groupId": "bridge",
    "translation": [0, 0, -3],
    "rotation": [0, 90, 0],
    "duration": 1.5,
    "easing": "smooth"
  }]
}
```

角色到达按钮中心才触发。`once` 每次试玩只触发一次；`toggle` 离开后重新踩入，在目标姿态和初始姿态之间切换。目标位移/旋转始终相对地图初始状态，不累加；每个开关最多 20 个动作，同一组不能重复。动作同时开始，可分别设置时长；`smooth` 使用平滑起止，`linear` 为匀速。如果组上有角色，角色随该组一起移动。新开关开始时暂停原有行走路线，动画结束后重新选择道路，避免沿旧路径走进空中。

多个开关可控制同一组，后触发者从当前姿态动画到自己的目标。拖拽控制同组时，其参数作为开关姿态上的额外位移/旋转。

## 海面与立柱

11 号是不可行走的海面，`length/width` 控制范围，`colors.surface` 控制颜色。`water` 包含 `amplitude`（0～0.4 格，默认 0.08）、`speed`（0～3，默认 0.65）、`wavelength`（1～20 格，默认 4）；编辑、试玩及独立游戏中均持续轻微起伏。

12 号是不可行走的纤细立柱，`rise` 为高度（0.1～20），`width` 为柱径，`colors.surface` 为颜色。可作为独立装饰，或用 `attachment: {pathId, corner}` 逐根依附于 1 号普通路径。角编号 0/1/2/3 分别为 X−Z−、X+Z−、X+Z+、X−Z+；每条路径的每个角最多一根。附着立柱的 `position/rotation` 为相对角点的局部偏移/旋转，`groupId` 必须为 null，变换自动跟随路径及其物体组。复制路径同时复制其立柱，删除路径同时删除其立柱；将路径拆成三棱柱时，原立柱保留在世界位置并解除依附。这些操作均支持撤销。

旧地图缺少 `water` 或 `attachment` 时分别采用默认参数和 null。`seaside-garden.json` 展示四角立柱及转动手轮 90° 后落成道路的桥。

## 错觉连接

`opticalLinks: [{a:"road-a",aEnd:1,b:"road-b",bEnd:0}]` 明确声明可发生视觉连接的端口：普通方块的 `0/1/2/3` 分别为局部 `X−/X+/Z−/Z+`；楼梯、圆弧、扭转道路只使用 `0` 起点和 `1` 终点；半块 A 有 `0/3/4`，半块 B 有 `1/2/4`，其中 `4` 是对角切面。扩展面端口使用 `10 × 面编号 + 边编号`：面编号 1 为底面，2/3 为 X−/X+，4/5 为 Z−/Z+，6 为三棱柱斜切面；底面边 0～4 对应原顶面规则，竖直面边 0/1 为轮廓两端的竖边，2/3 为顶部/底部横边。原 0～4 编号保持兼容，导入会检查端口是否属于该构件。

世界距离小于 0.065 格且法线同向的端口自动相连；显式错觉接缝还要求屏幕投影距离小于 0.055 格。默认等轴投影为 `u=(x-z)/√2`、`v=(2y-x-z)/√6`；视角旋转时使用引擎相机的实际右/上向量重新投影。三棱柱切面的完整投影重合且两半占据相反投影区域时，切面边界自动形成接缝，包括正好接在该边界上的普通道路。跨缝两侧必须有同向的可行走面；普通画面重叠不自动成为路口。

跨越错觉接缝时改变角色三维深度而保持屏幕位置连续。每次选择道路都从当前姿态重建连通图；动画期间暂停选择新路线。编辑器与地图游戏均提供旋转视角和复位等轴视角；相机状态不写入地图 JSON。为避免跨缝过程中改变投影，角色行走或机关动画期间暂停视角旋转与复位。

## 校验与加载

最多 500 个对象、100 个组、1000 条错觉接缝。拒绝未知版本/编号、重复 ID、悬空组与端点引用、非有限数值及越界参数；ID 为 1～64 位字母、数字、下划线或连字符，并保留 `__proto__`、`constructor`、`prototype`。导入失败保留现有地图。Schema 校验结构，跨对象引用及 ID 唯一性由共享 `parseMap` 校验。

试玩要求恰好一个出生平台、至少一个出口，并且所有开关有有效的非空目标组。运行时可通过 GUI「载入地图」选择本地 JSON，或在游戏页面追加 `?map=./maps/switch-garden.json` 从同源 URL 加载。URL 模式也会进行相同校验。
